## 1. 今回決めたことと、根拠がまだないこと

[同じ2パネルの感度比較](mgmfrm-foundation-scale-acceptance.md)では、負荷量の事前幅により
中心化能力、次元内負荷量比、学習内予測が変化した。小さいRMSEを与えた事前の採用には進まず、
**normalized exchangeable Cを比較基準として保持し、固定facet条件でも3幅を比較する**案とする。
旧rawのR1でのI2過少被覆は未解決の別の証拠であり、Cで解決したとも再現したとも言えない。

| 指定 | 今ある根拠 | 科学的な尺度採用に必要なもの |
| --- | --- | --- |
| exchangeable構造 | IDを付け替えても評定者の事前を変えないという対称性 | 対象の評定者を同じ分布で扱うことの妥当性。群差・既知の訓練差があれば別のモデル判断 |
| 人物SD 1、平均0、相関0 | 今回の生成母集団と推定単位を明示する基準 | 現実の母集団分布を確認した値ではない。生成後の50人を標準化してこの条件を強制しない |
| 項目SD 1 | Cの比較基準 | 項目位置の幅と応答確率への含意の測定上の根拠 |
| log負荷量の中心0、SD 0.25 / 0.5 / 1.0 | 中央値1を共通とする感度設定。0.5は既存の参照値 | 特定の負荷量・次元内比として許容できる事前範囲。中心0も単なる無情報指定ではない |
| 厳しさ・ステップのkernel SD √2、log一貫性のkernel SD √2/2 | 旧rawの平均周辺分散に合わせた計算上の由来 | 厳しさ差、一貫性比、ステップ差としての妥当な幅。分散合わせだけでは科学的根拠にならない |

単一の活動負荷量と、特定の同次元の一対の比について、中央95%事前範囲を数値に戻す。
全項目・全対比を同時に95%で覆う範囲ではない。

| log負荷量SD | 負荷量の95%範囲 | 一対の負荷量比の95%範囲 | P(a≤0.35) | P(a≤0.5) |
| --- | ---: | ---: | ---: | ---: |
| 0.25 | 0.613–1.632 | 0.500–2.000 | 0.00134% | 0.278% |
| 0.5 | 0.375–2.664 | 0.250–3.998 | 1.788% | 8.283% |
| 1.0 | 0.141–7.099 | 0.0625–15.988 | 14.690% | 24.411% |

P(a≤x)=Φ(log(x)/SD)であり、真値そのものに置く点確率ではない。
下記R1のI1=0.35、I2=0.5は、特にSD 0.25に対する縮小のストレス条件となる。
この条件での差だけから広い事前が一般に優れているとも判断しない。
他の事前ブロックの幅は今回は固定し、その頑健性を同時に検証したことにしない。
[尺度・対比の導出](mgmfrm-prior-choice.md)と[事前応答の確認](mgmfrm-prior-responses.md)を根拠として併記する。

## 2. 何を固定して、何を新しく生成するか

既存の[独立生成器](../../scripts/mgmfrm_core_reference.py)の`recovery_raw`を再利用する。
過去に検討したR0/R1を採用するため、設計選択自体が未観察・盲検だったとは扱わない。
以下を固定し、新しいseedの人物と回答について性能を調べる案である。
条件を無作為に抽出した母集団への平均性能ではない。

| 要素（ID順） | R0 | R1 |
| --- | --- | --- |
| 活動負荷量 I1–I5 | (0.7, 1.3, 0.7, 1.0, 1.3) | (0.35, 0.5, 0.7, 1.0, 1.3) |
| 項目難易度 I1–I5 | (−1, −0.5, 0, 0.5, 1) | 同じ |
| 厳しさ R1–R5 | (−0.8, −0.4, 0, 0.4, 0.8) | 同じ |
| log一貫性 R1–R5 | (−0.4, −0.2, 0, 0.2, 0.4) | 同じ |
| 各項目の隣接ステップ3個 | (−0.8, 0, 0.8) | 同じ |
| Q | I1/I2がD1、I3/I4/I5がD2 | 同じ |
| 各人物の能力 | 毎反復、独立N(0,I₂)から50人 | 対応するR0と同じ人物真値 |
| 応答 | 全1,250セルで条件付き独立なカテゴリー抽出 | R0と同じセル別一様乱数を条件別確率の逆CDFへ入れる |

ステップ保存形式の先頭0は、上の3隣接ステップとは別の基準カテゴリーの値である。
人物IDは実際の辞書順（P1, P10, …）で照合し、項目・評定者・QもIDで結合する。
実現した人物平均・SDを補正せず、真値による事後の位置・尺度合わせ、次元の並べ替えもしない。

独立反復単位は**R0/R1の一組の新しい人物・応答生成**とする。N組なら2Nパネル、
各パネルをSD 0.25/0.5/1.0で推定して6N fitとなる。R0/R1内では人物と応答一様乱数を共有し、
別組では生成乱数を分ける。同一パネルの3事前には同一入力を使い、fitの乱数系列は分ける。
seedが異なることだけで独立性が証明されたとはせず、RNG方式・割当・実行環境を実行票に残す。

R0/R1のD2では真値と応答確率が同じなので、対応する750評定は同一になる。
ただし**推定では両次元が評定者パラメータを共有する**ため、D2の事後分布が同じになるとは限らない。
D2の変化を直ちに実装エラーと解釈しない。

## 3. 比較対象と評価量

推定側のモデルと事前はCの明示指定を使い、log負荷量SDだけを変える。
基準0.5のR1−R0、各条件内での0.25−0.5／1.0−0.5を事前指定の記述的対比とする。
必要な交互作用は、同じ組で`(R1の事前差)−(R0の事前差)`を作る。
基準0.5は計算参照であり、科学的な主事前として採用する意味ではない。

| 対象 | 点推定・区間の評価 | 解釈の限界 |
| --- | --- | --- |
| 人物の相対能力（各次元別） | 各drawと真値からそれぞれ50人平均を引く。パネル内MSE、90%等裾被覆率、平均区間幅を作り、その後にパネル間集計 | 中心化は位置だけを除く。能力単位への依存は残る。中心化後の平均符号付き誤差は構造的に0なので主指標にしない |
| 絶対能力と人物平均 | 絶対MSEと平均位置の誤差、人物平均の事後SD。`絶対MSE=中心化MSE+平均位置誤差²`を保持 | 相対能力の良好さで絶対位置の不確実性を隠さない |
| 全5活動負荷量と4次元内log比 | 各IDのbias、MSE、90%被覆、区間幅。log比は各drawから計算 | I1/I2だけで通過扱いにしない。条件付き固定facetの被覆は共同事前SBCの被覆ではない |
| その他のfacetと元150量 | 既存の量・警告・失敗を全て保存し、条件別に記述 | 新しい焦点量を設けても、元の全150量の積極的較正主張を達成したことにはしない |
| 予測 | 今回はC4の主評価に含めない | 学習内の真の確率との比較を追加しても、未観測評定の予測性能や新しい評定者への一般化にはならない |

既存の`mgmfrm_core_recovery_review.jl`と`mgmfrm_foundation_sensitivity.jl`の量定義を使う。
50人、1,250評定、4,000draw、あるいは150量を独立反復件数にしない。
固定facetにおけるBayesian区間の頻度論的被覆は、この設計で調べる性質であり、
properな事前や数値診断通過だけから名目90%が保証されるものではない。

## 4. 二種類のMonte Carlo誤差と失敗の扱い

各fitは直前と同じ4チェーン、warmup 1,000＋保持1,000、変換座標、target_accept 0.9、
最大深さ10、diagonal metric、rawゼロ初期値＋jitter 0.1を候補とする。
元150量・位置残差・samplerの診断に、追加111量のR-hat≤1.01、bulk/tail ESS≥400、
平均MCSE/事後SD≤0.05、90%区間端MCSE/区間幅≤0.05を接続する。
診断・精度条件は実行前に固定し、fit内のMCMC誤差と、以下の反復間MCSEを分けて保存する。
被覆の境界付近は既存の区間端MCSEに基づく未確定扱いを維持する。全量のe/u保証は未確立のままである。

組jのパネルMSEをM_jとすると、報告するRMSEは`√mean_j(M_j)`である。
`mean_j(√M_j)`ではない。組ごとの性能量T_jの平均の反復MCSEは`SD(T_j)/√n`。
対応する二方法A/Bの平均差では、先に`T_Bj−T_Aj`を作り、そのSD/√nを使う。
RMSE差の一次近似MCSEは、共通の適格組について
`SD(M_Bj/(2 RMSE_B)−M_Aj/(2 RMSE_A))/√n`とする。
片側RMSEが0、組数≤1、非有限値、独立性の根拠不足では保留する。
この算術は[既存の対応集計](../../scripts/mgmfrm_core_summaries.jl)と同じで、新しい集計エンジンは作らない。

反復間のばらつきには残存するMCMC誤差も含まれる。fit内MCSEを再加算したり、推定根拠なく差し引いたりしない。
1人の精度不足を除いて49人へ再正規化せず、その次元のパネル量を未確定とする。
失敗・未実行は全予定N組に残す。各対比は必要なfitが揃う組だけで連続量を計算し、
使用IDとn/N、適格組への条件付き集計であることを明示する。全6条件を一括比較する表には共通の適格組を使う。
欠測を含み、上限・下限を事前指定していないRMSE/biasに、全N組の有限な上下限を作らない。

被覆のパネル割合は[0,1]、対応差は[−1,1]なので、未確定組にそれぞれの端点を入れた
全予定分母の記述的上下限を併記できる。これは信頼区間や有限MCMC誤分類の保証ではない。
人物数を二項分母にせず、パネル割合のSDから反復誤差を求める。
再生成、失敗の置換、結果を見たdraw延長や追加反復は行わない。

設計を目的・生成・対象量・方法・性能に分け、反復数をMCSEと結び付ける整理は
[Morris, White & Crowther (2019)](https://pmc.ncbi.nlm.nih.gov/articles/PMC6492164/)を参照した。
ここでのモデル固有の条件・失敗規則は本プロジェクトの設計案である。

MCSE、RMSE、事前感度の実用的許容幅へ読み替えない。

### 未確定率には、Nだけでは消えない制約がある

**単一の固定量**について、N反復のうち真値を含む判定がK件、未確定がU件なら、
全予定分母での記述的範囲は`[K/N, (K+U)/N]`、幅は`U/N`である。
ここでは確定した判定が正しいという理想化を置く。実際の2 MCSEスクリーニングには誤分類保証がない。

この範囲全体が`[0.9−δ, 0.9+δ]`に収まり得るには`U/N ≤ 2δ`が必要であり、
さらに整数Kが`ceil(N(0.9−δ)) ≤ K ≤ floor(N(0.9+δ))−U`を満たす必要がある。
Kの位置も必要なので、未知件数が下表以下というだけでは範囲内と判定できない。

| N | ±2.5ポイントで範囲内に置ける最大U | ±5ポイント | ±7.5ポイント |
| --- | ---: | ---: | ---: |
| 8 | 0 | 0 | 0 |
| 32 | 1 | 2 | 4 |
| 128 | 6 | 12 | 18 |

例えばN=8、U=1では幅12.5ポイントなので±7.5ポイントの幅15ポイントより小さいが、
どの整数Kでも範囲全体を82.5–97.5%に置けない。N=32、±5ポイントでは最大U=2であり、
連続近似の`floor(2δN)=3`をそのまま採用できない。
未確定率が一定に残れば、この記述的範囲の幅はNを増やしても残る。

**これは信頼区間・検出力・必要反復数・較正受入の規則ではない。** 観測Kの不確実性、
有限MCMCの誤分類、全150量の同時性を含めていない。人物平均被覆のKへこの整数表を適用しない。
3つのδは比較材料として残し、今回の2/6を将来の未確定率と推定して件数へ代入しない。
