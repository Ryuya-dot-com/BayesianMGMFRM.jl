# 応用から具体化する MGMFRM の受入・検証設計

更新：2026-09-21。状態：**合成応用例に一致するA0参照を実装し、Julia/Stanの数値照合・短い推定・保存再読込みまで確認。十分な事後精度、科学的受入、独立レビューは未確認。**

この文書は、[ロードマップ](../../ROADMAP.md#next-implementation-handoffs)の受入資料を、利用者の問いから具体化するものです。既存の固定係数 MFRM の検証計画を MGMFRM の証拠に読み替えたり、新しい実験制御基盤を作ったりするものではありません。コードの既存ターゲット、既定の事前分布、公開範囲は変更しません。合成例の生成に続き、[A0の参照推定](paired-rating-reference.md)を開発用スクリプトとして実装しました。実データへの推定、反復回復評価、SBCは実行していません。合成例の経路に実データの再照合は必要ありません。

## 1. 最初に支えたい応用上の答え

第一の利用場面は、**複数の評価基準で得た評定から、対象者の特徴と評価条件による違いを、不確実性付きで説明すること**です。初回の受入範囲には、自動合否、評価者の排除、介入の因果効果は含めません。利用者が判断に使う境界・損失を定めていない段階では、独自の合格点や「実用上同等」の数値を置かず、説明的な結論を目指します。

具体例は Uchihara (2022) の語発音課題を参考にした**合成データの応用例**です。「分かりやすさ」と「訛りの強さ」を区別して測定し、音声特徴との関係を調べるという元研究の目的を踏まえます。[原論文・抄録](https://www.sciencedirect.com/science/article/pii/S2772766122000088) 今回は実際の観測値を合成値と呼び換えるのではなく、独立に生成した架空の対象・評定を用います。元研究の追試や実際の話者についての結論は扱いません。

応用は、検証する推定対象・情報不足・依存構造を選ぶ根拠になります。一方、この一研究を再現できたことだけでは、別の語彙、集団、評価基準、割当構造での一般的な妥当性は保証されません。パッケージの最初の受入候補である独立次元 MGMFRM と、この応用で必要な相関・録音効果を持つモデルは別のターゲットとして管理します。

| 利用者と問い | 必要な推定対象・出力 | 検証する理由と、言えることの限界 |
| --- | --- | --- |
| 研究者・教育者：同じ話者について、分かりやすさと訛りをどう説明するか | 基準名を付けた話者プロフィール、基準内の話者間対比、同じ録音群に対するカテゴリー確率と区間 | 異なる語の産出数や評価条件を、単純平均の差に混ぜない。二つの潜在尺度の差をそのまま「能力差」と呼ばない。語の想起後に得た発音評定から一般的な語彙力・会話能力へ外挿しない |
| 研究者：二基準はどの程度関連し、別々に報告する意味があるか | 話者母集団の相関 `rho_person`、その区間・事前感度、対応するプロフィール・予測の違い | 12話者の情報量を19評価者の反復で水増ししない。録音の共変動、全評定の単純相関、事後標本内の相関を区別する。相関が1未満という事実だけで構成概念の独立性を認定しない |
| 評価運営者：評価者が基準を使い分けているか | 同じ基準内の評価者対比、基準別厳しさ、必要なら一貫性の予測上の影響 | 任意の評価者 ID・割当・事前分布への依存を検証する。極端な応答や低い一貫性だけで「不適格」と分類しない |
| 研究者：一般化モデルを使う利点は何か | 固定係数参照に比べた区間校正、カテゴリー予測損失、話者・評価者対比の変化と計算失敗率 | 当てはまりの改善だけで採用しない。負荷量と一貫性を同時に自由化した比較から、それぞれ単独の効果を主張しない |
| 研究者：音声特徴は二基準と違って関連するか | 同じ適格録音における予測カテゴリー効果、基準間の効果対比、未調整／調整後の話者の意味 | 片方で有意・他方で非有意という比較を避ける。特徴量欠測による対象集団の変化を、調整の効果として説明しない。因果効果は対象外 |

優先順位は、プロフィールと測定の妥当性、評価者差、一般化による追加価値、特徴量による説明、認識・処理時間への関連の順とします。後半の分析を増やして、前半の測定上の問題を埋め合わせません。

この応用から汎用化する要件は、録音という名称に依存しません。作文を「内容／言語」、面接や遂行課題を複数の観点で評定する場面でも、同じ作品・遂行への反復評価、基準ごとの評価者差、課題の不均衡、観測済みの対象と新しい対象への予測の区別を点検する必要があります。人・課題・評価者だけでなく「評価される一つの作品／遂行」と基準を追跡できることが再利用可能な要件です。ただし、これらは構造の類似に基づく設計上の含意であり、この発音データの検証結果や2次元の対応範囲を、そのまま他用途へ移せるという主張ではありません。

### 合成例のデータ契約と実行

[生成例](../../examples/synthetic_paired_ratings.jl)は、ワークブック、実際のID・評定・音声特徴・割当位置を読みません。上記の観察から、二基準、反復評価、不均衡、少数話者しか持たない語という構造を選びました。既定では12話者・37語・19評価者・9カテゴリーを使いますが、録音数、割当位置、欠測位置、評定値を実データに合わせ込んでいません。12人は母相関の精度が課題になる説明用の設定であり、推奨標本数ではありません。

```sh
julia --project=. examples/synthetic_paired_ratings.jl
```

新しい出力先を引数として指定することもできます。既存の出力先への上書きは拒否します。追加依存パッケージはありません。

| ファイル | 内容・読み方 |
| --- | --- |
| `ratings.json` | 観測された基準だけの縦長評定。架空の話者・物理語・評価者・録音・基準・語×基準項目ID、0–8のスコア。片方の欠測で相方を削除しない |
| `recordings.json` | 全444話者×語セルと割当の有無。録音がないセルに評定0を補わない |
| `truth.json` | 話者・語・評価者・録音効果、基準別ステップ、二つの母相関と生成SD、実現した話者標本相関、割当済みセルの欠測前スコア・条件付きカテゴリー確率。観測データと区別して照合に用いる |
| `manifest.json` | 合成であること、式、スコア方向、各乱数系列のseed、人数・行数、割当・欠測規則、生成元と出力のハッシュ、Julia版、用途と限界 |

設計上、最初の3語は全員、次の32語は確率0.7で割り当て、2人未満なら無作為な2人へ置き換えます。最後の2語はそれぞれ無作為な1人・2人だけに割り当てます。すべての割当済み録音を19評価者が二基準で評価し、第一基準だけ独立な確率0.005で欠測させます。設計・人物・語・評価者・録音・応答・評定欠測の乱数系列を分けています。都合の悪いスコアやカテゴリー欠如を理由に生成をやり直しません。接続した設計を保つ操作は応答生成前の明示した割当規則です。

生成値は `rho_person=0.6`、`rho_recording=0.25`、録音SD `(0.45,0.60)`、語難易度の生成SD `0.65`、基準別評価者の投影前SD `(0.40,0.55)` です。話者は周辺SD1の二変量正規から生成し、有限標本を平均0・SD1・相関0.6へ調整しません。評価者は基準別に中心化するため、生成共分散は各基準で `tau_c^2 (I-11'/R)` です。録音効果は全候補セルについて一度だけ生成し、割当済みセルでは19評価者・二基準で共有します。基準別の8ステップをそれぞれ `[-1.4,1.4]`、`[-1,1]` の等間隔・ゼロ和とし、別に基準カテゴリー0の固定ステップ0を保存します。係数・一貫性は1で、式は次節のA0に一致します。これらの数値は説明用の生成条件であり、実データからの推定値でも推定時の事前分布でもありません。

話者数だけを変更する小さな比較用には、[生成処理](../../scripts/synthetic_paired_ratings.jl)を `include("scripts/synthetic_paired_ratings.jl")` で読み込み、`SyntheticPairedRatings.generate(persons=48)` または新規ディレクトリへの `write_example(path; persons=48)` を使えます。対応する新しい48人を生成し、12人の評定を複製しません。これは比較の入力を作る機能であり、V0–V1の回復評価はまだ実施していません。公開例はこの生成処理を呼ぶ入口であり、新たなパッケージAPIは追加していません。

2026-09-21の既定seed `92151` の[生成出力](../../results/workflows/20260921-synthetic-application-01/example/manifest.json)では、444候補セルのうち292録音を割り当て、152セルは不在でした。欠測前の評定は11,096件、第一基準の欠測28件を除く観測評定は11,068件です。実データの307録音・11,660評定とは異なることを保持しています。同じ生成元・seed・記録されたJulia環境で再現し、実行環境を変えた場合のバイト同一性は前提にしません。[検証記録](../../results/workflows/20260921-synthetic-application-01/verification.json)には、高精度の独立な正規化式、共有録音効果、欠測相方、乱数再現、保存内容を点検した範囲を記録しました。最終配置での集中テストはJulia 1.12.5で511項目、1.10.8で515項目が通過しました。生成された欠測行も確率照合に選ぶため、乱数実装が異なる環境間で検査数の一致は要求しません。公開ソース・新規生成HTML・実行出力の検査も通過しています。これは作成者による工学的検証であり、独立した科学的レビューや全体CIの代わりではありません。

生成例で答えられるのは、既知の生成構造を欠落なく表現・再現できるかです。これに加え、A0参照の限定的な推定経路が動作することを確認しました。単一データの真値を保存できることや短い推定が完走することは、推定の正確さ、被覆、二尺度の必要性の証拠ではありません。現行の通常MGMFRMにこのデータをそのまま渡しても録音効果・基準別評価者・基準共通ステップは表現されないため、参照スクリプトと通常APIを区別します。音声特徴、認識、処理時間、能力に依存する産出欠測は生成していません。

## 3. 応用モデルの最小候補と実装の境界

以下は**限定的な参照実装にした数式候補**です。上記の生成例と反応式を揃えましたが、独立した科学的レビューは未実施です。現在の MGMFRM をそのまま当てはめたモデルではありません。`p` は話者、`w` は物理的な語、`r` は物理的な評価者、`c` は二つの基準、`omega=(p,w)` は録音を表します。[参照実装の事前・自由座標・正規化・結果の契約](paired-rating-reference.md)を併せて確認します。

合成例では直接 `Z=0,...,8`（高いほど分かりやすい／訛りが弱い）を生成します。将来、実データを使う場合に限り、元の1–9評定の方向を照合した後に `Z=9-Y` とする案を再確認し、元評定を保持します。「訛りが弱い」を「総合的に優れている」と読み替えません。

固定係数・単位一貫性の参照モデル A0 は、隣接カテゴリー `h=1,...,8` について

```text
log Pr(Z_pwr,c = h) / Pr(Z_pwr,c = h-1)
    = theta_p,c - b_w,c - r_r,c + u_omega,c - s_c,h

theta_p ~ N_2(0, [[1, rho_person], [rho_person, 1]])
u_omega ~ N_2(0, Sigma_recording)
sum_r r_r,c = 0   (each criterion)
sum_h s_c,h = 0   (each criterion; stored baseline step s_c,0 = 0)
```

- **相関の階層を分ける。** `rho_person` は話者差、`Sigma_recording` は話者・語を考慮した後の録音ごとの共変動です。後者の標準偏差2個と相関1個を持つ候補とします。既定の合成例では話者12人・録音292件（確認した実データでは12人・307件）という異なる情報量を保持し、同じ相関を両階層へ使いません。対角の録音共分散や録音効果なしは制約の検証用です。反復評定だけで話者数が増えたかのような推論を避ける目的があります。
- **語×基準は純粋 Q の測定項目。** 両基準を同じ語で測ること自体は、1反応が両能力へ負荷する within-item モデルを必要としません。物理的な語・録音IDを別に保持します。自由な `b_w,c` に、さらに制約のない語主効果を重ねません。
- **共通の評定基準を先に検証する。** 同じ9段階ルーブリックを各語に使う候補として、ステップは基準内で語間共通とします。項目ごとにすると74項目×7自由ステップ=518個、共通なら2基準×7=14個です。節約だけを理由に共通化を採用せず、語・カテゴリー別の予測とステップ異質性の感度条件で制約を調べます。現行の項目別ステップモデルと同じターゲットではありません。
- **評価者は物理IDを保ち、基準別に表す。** `r_.c` は基準ごとのゼロ和ベクトルとし、独立な基準別の交換可能正規事前を出発候補とします（共分散 `tau_c^2 * (I - 11'/R)`）。`tau_c` は固定入力として予測的に吟味します。評価者 ID×基準を連結して既存の単一ゼロ和制約へ入れる方法を、この契約の代用にしません。評価者の母集団相関や個別ルーブリックの使用過程まで推定する案ではありません。
- **尺度と事前分布を明記する。** 話者の周辺SDを1とする候補、固定する語難易度・ステップ・評価者の尺度、録音SDの proper な正の事前分布、二つの相関の LKJ 形状を明示します。A0は負荷量とロジット係数も1に固定するため、話者SD1は単なる尺度識別ではなく、話者母集団の広がりへの追加仮定です。生成もSD1とする確認はこの条件内に限定され、異なる話者分散への頑健性を示しません。具体値は事前予測と科学的レビューで決め、採用前の既定値にはしません。位置を定める役割と分布への実質的な仮定を区別し、限られた話者数での事前感度を報告します。
- **残る条件付き独立の仮定を検証する。** 同じ評価者が同じ録音へ付ける二評定には、録音共通効果とは別の依存が残り得ます。このモデルは評価者×録音固有の二基準依存を追加していません。基準対の残差検査と、これを含む生成条件で焦点推定への影響を確認します。必要なら次の限定拡張とし、すべての階層に共分散を追加することを初期要件にはしません。

一般化による追加価値を問う場合は、同じ A0 の単位ロジット尺度で `theta` を `a_w,c * theta` に置き換える A-L、括弧全体へ正の `gamma_r` を掛ける A-C を別々の候補にします。後者は当初、基準間で共通の評価者一貫性、`prod_r gamma_r=1` とする制約を持ちます。基準別一貫性が必要なら別モデルとして明記します。A-LC は両方を自由化した効果だけを評価します。比較対象・データ・ステップ・録音効果・共有パラメータの事前は揃えます。

現行 MGMFRM のリテラル `1.7` と raw-coordinate prior を保ったモデルと、この単位ロジット候補をそのまま入れ子の比較にしてはいけません。A0との条件付き一致を保証する尺度写像・事前測度・固定パラメータ操作を先に実装・検証します。固定値の代用に事前SD=0を渡しません。上記を実装せずに現行の自由負荷量モデルを走らせても、この応用契約を満たしません。

「一つの話者特性で報告できるか」まで答える場合には、A0の `theta_p,c` を一つの `theta_p ~ N(0,1)` に置き換え、同じ録音・評価者・ステップ構造を保つ共通次元参照 A-1 を別の正規化されたモデルとして定義します。二次元サンプラーへ `rho=1` を渡して代用しません。この参照の等しい能力係数という制約も明記し、必要なら基準別係数の案を別にレビューします。共通次元と二次元の比較では、分割した予測・プロフィールの意味・事前感度を併せて評価します。A-1を比較しない段階では、A0の相関とプロフィールの記述に結論を限定し、「二尺度が必要」と断定しません。

| 通常のパッケージが提供する基盤 | 応用に向けた参照実装と残る選択 |
| --- | --- |
| 明示的な2次元相関、固定係数／推定負荷量の別ターゲット、Julia/CmdStan、事前・既存行の事後予測、診断・MCSE、保存・レポート・図 | A0参照スクリプトで録音効果、基準別評価者、基準共通ステップ、両バックエンド、共同事前の生成と既知／未知録音への予測を実装。事前の科学的選定、十分な推定精度、通常APIへの統合とその受入は未完了 |
| 既存の人・項目・評価者に条件付けた予測 | 未知の録音効果を積分した予測、基準を束ねた録音単位の分割・再推定、選択的な産出欠測への仮定 |

## 4. 応用の問いに対応する最小検証条件

まず、A0と採用候補1つの一般化ブロックまでをレビュー対象にします。すべてのモデル×条件×事前を総当たりしません。独立した生成式で確率・制約・真値の対応を確認し、各条件の目的に必要な比較だけを行います。以下の真値・効果量・事前の数値と実行数は、実行前に固定する項目です。

| 条件と問い | 変えるもの／保つもの | 測るものと結論 |
| --- | --- | --- |
| V0：応用に近い条件で基本的な不確実性を回復できるか | 12話者、37語、19評価者、9カテゴリー、二基準。上記の合成割当・欠測規則を出発候補とし、評価では固定マスクに条件付けるか規則から再生成するかを事前に選ぶ。A0から話者を各反復で新たに生成 | 基準内話者対比、`rho_person`、評価者対比、記録済み設計上のカテゴリー確率の偏り・区間被覆・幅・失敗率。実際の割当位置は入力にしない。真値から独立な割当を用いた検証であり、実際の産出欠測が無視可能という証明ではない |
| V1：母相関の情報不足は話者数から来るか | V0と同じ語・評価者・一人当たりの割当規則を使い、48話者へ拡大。12人を反復IDで複製しない | 相関区間・事前感度・被覆の変化。これは将来のデータ収集設計の比較であり、現在の12人の結論を精密化した結果とは扱わない |
| V2：録音依存を省くと、何を誤るか | 同じ V0 の生成データに A0 と録音効果なしの制約モデルを当てる。生成では話者相関と録音相関を区別 | `rho_person` とプロフィール区間のずれ、過小被覆、残差依存。省略モデルが失敗する結果も有益な検証結果 |
| V3：基準別評価者差が必要か | 基準で異なる厳しさを持つ生成と、共通厳しさの制約モデルを比較。他の構造・観測値を揃える | 基準内の評価者対比、話者プロフィールへの影響、同じ基準・録音条件での予測差。評価者を罰する分類は行わない |
| V4：負荷量を推定する情報と利点はあるか | 1–2話者しか持たない語を含む V0 の割当を保ち、固定負荷量の真値と事前指定した異質な負荷量の真値を区別。A0 と A-L を必要な組合せで比較 | 負荷量・難易度の事後依存、事前感度、人物・予測の精度と失敗率。反復評価者が多くても低被覆語の傾きが十分回復しない可能性を正面から評価する。A-Cを選ぶ場合は一貫性の問いに置き換え、A-Lの結果と混ぜない |
| V5：観測された産出への条件付けはどこまで通用するか | 応用の割当を固定する条件とは別に、潜在特性と語に依存する産出選択を生成。平均被覆を近づけても同じ欠測機構とは扱わない | 産出した語に条件付けた量と、全語・全集団の量について偏りを分ける。選択モデルを持たない推定の適用範囲を狭めるためのストレス条件 |
| 必要時の限定感度 | 基準共通ステップに対する語別異質性、評価者×録音の残る二基準依存、相関・録音SD・評価者事前の変更を一度に一つ検討 | 焦点となるプロフィール・相関・予測がどれほど変わるかを示す。単に不適合を検出するだけで終えず、答えへの影響を報告する |

V0–V1の母相関の被覆では、同じ12人の能力を固定して評定だけ再生成せず、母集団から話者を引き直します。一方、既知の語・評価者を対象にする固定真値回復と、これらも事前から生成する joint-prior SBC は別実験です。SBCの成功は、選んだ事前や応用データへのモデル適合を保証しません。[既存プロトコルのSBC区分](fixed-coefficient-validation-protocol.md#joint-prior-calibration-is-a-separate-experiment)を再利用し、数式・真値のロスターはこの新ターゲットに作り直します。

追加評価者・語の削減を現実の運用案として推奨するのは、割当ごとの費用と許容損失が決まってからです。今回のV1は「話者を増やすと母相関の情報が増えるか」という一つの問いに限定します。

## 5. 予測の対象、重み、判断基準を先に決める

第一の報告では、各基準の全カテゴリー確率または全累積確率を示します。特定の `Pr(Y <= k*)` を主指標にするなら、ルーブリック上の意味を利用者が確認して `k*` を先に定めます。今回のデータだけから「3以下なら十分」といった線を導入しません。

| 予測課題 | 学習時に使える情報・検証の分け方 |
| --- | --- |
| 同じ評定行への再現チェック | 現行の事後予測が扱う範囲。観測値と似ることはモデル診断の一部であり、未観測例への予測成績とは呼ばない |
| 既知の録音を、評定に使われなかった既知の評価者が評価する | 同じ録音の他評価者の評定を利用できるという課題を明記。物理的な評価者を学習全体から除く課題とは異なる。対になった二基準の利用可否を先に決める |
| 既知の話者・語について、まだ評価されていない録音の二基準を予測する | 録音単位で両基準・全評価者を一緒に除外して再推定し、未知の録音効果を事前から積分する。現行の既存行予測では代用できない。除外後も学習に話者・語が残ることを点検する |
| 新しい話者・語・評価者に予測する | 別の母集団・未知効果の積分・分割設計が必要。1話者しか産出していない語の録音を除くと、その語も未知になる。こうした折を黙って同じ課題に混ぜず、別に数えるか適用範囲を限定する |

評定確率の損失は各基準を同じ重みとし、まず録音内で評価者を平均し、次に録音を平均する案です。ただし、これは産出数の多い話者を重くします。「平均的な話者」を対象にする指標は、話者内で録音を平均してから12話者を等重みで平均する別の量として明示します。比較モデルは同じ適格観測・同じ重みを使います。全37語への標準化は、欠けた産出についての仮定が未確定のため主指標にしません。

未知の録音を対象にした成績では、カテゴリーの Brier score／log score と累積確率の校正を評価します。真値を知るシミュレーションでは、真の確率に対する予測損失と、実現した評定への損失を分けます。実データの折・録音・評価者を、独立な母集団反復として扱いません。12話者で得る汎化性能の不確実性はその単位に対応させ、少数クラスターで強い精度主張を避けます。

判断の基準は三層に分けます。

1. **計算が信頼できるか。** 全パラメータ／焦点対比の診断、MCSE、発散・木の深さ・エネルギー、両バックエンドの同じターゲットを確認します。MCSEは事後区間幅の代用ではありません。
2. **推定にどの性質があるか。** 偏り、区間被覆、幅、予測損失、事前感度、失敗・不確定率を、反復単位の誤差とともに示します。特に固定真値での95%区間の被覆は、ベイズ区間という名称だけから95%と保証しません。
3. **用途に十分か。** 許容するプロフィール差・確率誤差・損失を、何を判断するための量かと結び付けて採用します。未設定なら「この条件で幅はこの程度」「事前に敏感」「判断保留」という記述的結論に止めます。研究者がレビュー前に便宜的な数値を実用基準に格上げしません。

## 6. 計算量を先に膨らませない実行案

レビューする最初の費用パイロットは、**A0の応用形状データ1組を Julia/CmdStan で各1回、計2推定まで**とする案です。独立生成・両実装・保存後の焦点量の復元ができてから、パイロット専用の1組を生成します。V0–V5をこの時点で全実行しません。

候補制御は各4チェーン、500 warmup＋500 retained／chain。1推定30分、2推定の合計60分（コンパイルを含む）、プロセス群8 GiB、総出力2 GiBを上限候補とし、強制停止と計測を実装・レビューしてから実行します。これらは実測に基づく所要時間の予測ではなく、未承認の費用上限・短い観察用制御です。診断やMCSEが不十分でも自動延長・自動再試行せず、失敗または不確定として残します。パイロットを回復・SBCの反復に算入しません。負荷量の推定版や48話者条件の費用へ、この一組の所要時間をそのまま外挿しません。

[後続の事前レビュー](paired-rating-prior-review.md)で、全話者／評価者対比、二つの相関、録音SD、固定した予測設計を焦点量として具体化しました。平均・区間端のMCSE、積分誤差、診断不良と費用警告を分ける判定案も記録しています。その[consumerと実行中の資源監視](paired-rating-precision.md)は、保存済みの短い推定と限定したPythonテストで検証しました。各保存結果の4,354量はすべてMCSEを判断するには標本不足です。数値精度の提案は実用的な許容差ではなく、科学的な事前選定と完全なパイロット契約も未確定のため、新規推定の開始条件を満たしたとは扱いません。

本検証の反復数は、用途の許容誤差と実行費用を照合して決めます。独立なデータセットを単位とする二値指標では、目標MCSE `e` に対し `N ≈ p(1-p)/e^2` が出発点です。

| 計画上の例（採用値ではない） | 必要な独立反復数の近似 |
| --- | --- |
| 被覆が0.95付近、MCSE 0.02 | 119 |
| 被覆が0.95付近、MCSE 0.01 | 475 |
| 率が未知、最悪の場合でもMCSE 0.02 | 625 |

MCSEは95%誤差幅とは異なります。連続的な損失・対比では、反復間の分散や対応差の分散を用います。同じデータの二モデル、4チェーン、12人、19評価者は独立反復数を増やしません。必要な反復数と実測費用が予算に合わなければ、評価前に主張・条件を狭めるか、精度の低い記述的結論を採用します。既存の固定係数計画の5,780推定を最低要件として引き継ぎません。

全予定IDについて生成拒否、推定失敗、上限到達、診断不良、MCSE不足を数えます。成功例だけの区間被覆や平均誤差で全条件を受け入れません。既存の[失敗分母・不確定判定](fixed-coefficient-validation-protocol.md#scores-failures-and-decision-rules)を使い、対応するモデル比較では両モデルが評価可能な数と脱落理由も示します。
