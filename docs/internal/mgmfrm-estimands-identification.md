# MGMFRMの推定対象・識別性・事前による基準

2026-09-24。**完全交差・純粋Qの条件付き応答モデルでは、以下の非退化条件の下で、残る不定性は次元別の原点と正の尺度に限られる。能力差や項目位置差の全てが、それらに不変なわけではない。** 本書は実装済みの式からの導出と反例をまとめる。新しい推定、事前の採用、凍結したSBC計画の変更は行わない。

## 1. 問いと対象

人物・項目・評定者を比較する際、同じ応答確率を与えるパラメータでも比較値が変わるなら、その比較には基準の指定が必要になる。ここでは、何がデータの確率分布によって区別され、何が事前による原点・単位の指定に依存するかを問う。

対象は[現在の応答式](../src/model-equations.md)であり、原著の全モデルや全てのMGMFRM変種の識別定理ではない。特に、有限の人物能力を明示パラメータとする**条件付き応答分布**を調べる。能力を母集団分布で積分した周辺モデルの識別性とは別である。また、実際に得た一つの評定配列で対数尤度が同じというだけでは、統計モデルの非識別性の証拠にならない。以下では全セルの全カテゴリー確率が一致することを使う。

人物p、項目i、評定者r、カテゴリーk=0,...,K−1とし、H=K−1とおく。

```math
\ell_{pir0}=0,\qquad
\ell_{pirk}=\sum_{h=1}^k\lambda\gamma_r
  (a_i^\top\theta_p-b_i-s_r-\tau_{ih}),\qquad
\pi_{pirk}=\frac{\exp\ell_{pirk}}{\sum_{j=0}^{K-1}\exp\ell_{pirj}}.
```

倍率λ=1.7は固定。既知Qの非活動負荷量は0、活動負荷量とγは正とする。制約は `sum_r s_r=0`、`prod_r gamma_r=1`、各項目で `sum_h tau_ih=0`。保存上の基準ステップ0は、H個の隣接ステップに追加する自由閾値ではない。K=2では唯一の隣接ステップが0となる。カテゴリーの順序は固定し、ステップ自体の昇順制約は置かない。全パラメータを条件とした観測の独立性を仮定し、各観測カテゴリーの確率の積を尤度とする。

## 2. 原点と尺度の変換

任意のc_dと正のt_dについて、

```math
\theta'_{pd}=t_d\theta_{pd}+c_d,\qquad
a'_{id}=a_{id}/t_d,\qquad
b'_i=b_i+\sum_d a_{id}c_d/t_d
```

とし、s、γ、τを変えない。このとき `a_i'^T theta_p' - b_i' = a_i^T theta_p - b_i` なので、全隣接対数オッズと全カテゴリー確率が一致する。Qのゼロ、負荷量の正値性、全ての和・積制約も保存される。この方向の不変性は、純粋Qだけでなく交差負荷のある固定Qにも成り立つ。

これは条件付き尤度の不変性である。変換後の座標に元と同じ独立正規事前を置き直せば、一般には別の事後分布になる。元の事前を変換先へ正しく移す座標変更とは区別する。

## 3. 完全交差・純粋Qでの逆向きの導出

以下の条件を全て置く。

1. 全人物×全項目×全評定者セルが対象で、各セルに同じK≥2のカテゴリーが定義され、モデルはその全確率を与える。
2. 各項目は既知の一つの次元d(i)だけに正の負荷量a_iを持ち、各次元に少なくとも一つの項目がある。人物・項目・評定者・次元のIDは固定する。
3. 各次元で少なくとも二人の能力が異なる。全パラメータは有限、γは正で、上記の制約と固定λを満たす。

**命題：この範囲で二つのパラメータが同じ全カテゴリー確率を与えるなら、γ、s、τは一致し、残りは第2節の次元別変換で結ばれる。** 次の復元によって示せる。

### 3.1 評定者一貫性

全確率は正なので、確率から

```math
G_{pirh}=\lambda^{-1}\log(\pi_{pirh}/\pi_{pir,h-1})
       =\gamma_r(a_i\theta_{p,d(i)}-b_i-s_r-\tau_{ih})
```

を求められる。ある項目と能力が異なる人物p,qを選ぶと、

```math
\Delta_r=G_{pirh}-G_{qirh}
        =\gamma_r a_i(\theta_{p,d(i)}-\theta_{q,d(i)})\ne0.
```

従って、積1の制約から `gamma_r = abs(Delta_r) / geometric_mean_r(abs(Delta_r))` と一意に復元できる。同じ人物対・項目・隣接カテゴリーを全評定者で比較できることが必要である。

### 3.2 評定者厳しさ、項目ステップ、人物–項目予測子

`U_pirh = G_pirh/gamma_r` とおく。等重みの平均を上線で示すと、

```math
s_r=\overline U_{p,i,r,h}-\overline U_{p,i,h\mid r},\qquad
V_{pi}=\overline U_{r,h\mid p,i}=a_i\theta_{p,d(i)}-b_i,
```

```math
\tau_{ih}=\overline{(V_{pi}-U_{pirh})}_{p,r\mid i,h}.
```

最初の右辺第一項は全人物・全項目・全評定者・全隣接カテゴリーの平均である。sとτのゼロ和により、全て確率から一意に復元できる。

### 3.3 能力・負荷量・項目位置

`V_pi = a_i theta_pd - b_i` の人物方向の差を取る。同じ次元の一つの項目i₀について、二つの同値パラメータでは

```math
a_{i_0}(\theta_{pd}-\theta_{qd})
=a'_{i_0}(\theta'_{pd}-\theta'_{qd}).
```

正値性により `t_d=a_i0/a'_i0>0` とおけるため、全人物で `theta'_pd=t_d theta_pd+c_d` となる。他の各項目でも、能力が異なる人物対を使うと `a'_i=a_i/t_d` が従い、Vの一致から `b'_i=b_i+a_i c_d/t_d` となる。これで命題を示した。

### 成立条件と限界

これは確率分布からの構造的識別についての導出であり、各セル一回の評定から確率を正確に復元できるという主張ではない。「一項目／次元」でもこの条件付き同値類の議論は成立するが、十分な測定精度や標本数の推奨を意味しない。

ある次元で全員の能力がuなら、項目iだけの負荷量をa_iからa'_iへ変更し、`b'_i=b_i+(a'_i-a_i)u` としてもVは同じになる。同じ次元の他項目は変更しなくてよいので、負荷量比まで非識別になる。従って非退化条件を削れない。連結性などの構造検査だけでは、能力のばらつきや推定精度まで保証されない。

疎な割当てでは3.1–3.2の比較や平均を作れない場合がある。交差負荷では3.3の一次元因子分解を使えない。本書はそれらの識別条件を導いていない。第2節の変換に不変だからという理由だけで、これらの範囲でも識別済みとはしない。密な負荷量の回転反例と構造検査の限界は[既存検査](../../test/fixed_q_identification.jl)が扱う。相関パラメータは条件付き応答式に入らないため、本命題から潜在相関の識別性を主張しない。

## 4. 推定対象の分類と解釈

次の表は純粋Qで、同一次元の比較を基本とする。「不変」は原点移動cと正の尺度変更tに対する性質であり、「識別される」と言える範囲は第3節の条件下に限る。不変な量でも事後推論は事前や有限データに依存する。

| 推定対象 | 原点cへの不変性 | 正の尺度tへの不変性 | 比較としての意味 |
| --- | --- | --- | --- |
| 能力の絶対値θ_pd | なし | なし | 宣言した能力分布の原点・単位に依存 |
| 同一次元の能力差θ_pd−θ_qd | あり | 値はt_d倍 | 正負・順位は不変。差の大きさ、非零の実質的許容幅には単位が必要 |
| 能力の人物内標準化値 `(theta_pd−mean_p theta_pd)/SD_p(theta_pd)` | あり | あり | SD>0の同じ有限パネルに限定。母集団標準化とは別 |
| 負荷量a_i | あり | 値は1/t_d倍 | 能力単位を指定する必要がある |
| 同一次元の負荷量比a_i/a_j | あり | あり | 異次元比にはそのまま適用しない |
| 項目位置b_i | なし | c=0ならあり | 能力単位での閾値そのものではない |
| 同一次元の項目位置差b_i−b_j | 一般になし | c=0ならあり | 負荷量が異なれば原点の変更で正負も変わる |
| 同一次元の `b_i/a_i−b_j/a_j` | あり | 値はt_d倍 | 能力座標上の中心の差。正負は不変だが大きさは単位依存 |
| `b_i−a_i*mean_p(theta_pd)` | あり | あり | 同じ有限パネルの平均能力に対する項目位置。現在の位置診断が計算する量 |
| `a_i*(theta_pd−theta_qd)` | あり | あり | 同じ項目での人物差の予測子への寄与 |
| 厳しさs_r、その差 | あり | あり | ゼロ和で原点を固定した評定者効果。γが異なると得点の大小関係全体とは一致しない |
| 一貫性γ_r、その比／log比 | あり | あり | 積1の基準での倍率。実際の評定の信頼性や将来の一致率そのものではない |
| 隣接ステップτ_ih | あり | あり | 項目ごとのゼロ和とカテゴリー順序を維持する |
| 対応する人物・項目・評定者の応答確率 | あり | あり | パラメータと人物座標を一緒に変換した場合。固定数値の新能力点を据え置く比較は別 |

標準偏差の分母をN／N−1のどちらにするかは事前に揃える。人物パネルを変更すると、標準化値やパネル相対項目位置の対象も変わる。次元間の能力差・負荷量比を、そのまま共通単位での比較と解釈しない。

### 項目順位が変わる具体例

同一次元で `(a_i,a_j)=(0.8,1.6)`、`(b_i,b_j)=(0.2,0.1)` とする。c=1、t=1なら `b'_i=1.0`、`b'_j=1.7` である。全応答確率は同じでも、bの差は+0.1から−0.7へ反転する。一方、能力座標上の中心の差 `b_i/a_i−b_j/a_j` は0.1875で変わらない。

パネル相対項目位置や中心の差を「正しい比較」として一律に置換しない。どちらも異なる問いに答える。bの差も、宣言した母集団原点に条件づけた推定対象としては有効である。[既存の主対比](mgmfrm-first-acceptance.md#4-推定量予測判断の具体化)と凍結したSBC量を変更せず、その解釈条件を明示する。

## 5. 事前による基準と事後分布の存在

初回候補のraw座標は128個の独立した正規変数で、尺度は正で有限に固定してある。θのN(0,1)事前は母集団上の原点・単位を指定するが、有限パネルの標本平均を厳密に0、標本分散を厳密に1へ拘束するものではない。負荷量やbの事前も同時に作用する。これは条件付き尤度の不定性と矛盾しない。能力を積分した周辺モデルは、この母集団仮定を既に含んでいる。

**この候補の事後分布が正規化可能であることは、追加MCMCなしに示せる。** 有効な有限個のカテゴリー観測yと有限raw座標xについて、厳密な実数演算上は `0<L(y|x)≤1`。properなraw事前密度p(x)の積分は1なので、

```math
0<Z(y)=\int L(y\mid x)p(x)\,dx\le1.
```

従って `p(x|y)=L(y|x)p(x)/Z(y)` はproperである。Z>0は被積分関数が事前の下でほとんど確実に正なことによる。これは固定された有効なモデル・カテゴリー支持・properな事前の下での存在の証明である。浮動小数点でのオーバーフロー、推定の混合、パラメータ回復、事前の妥当性、区間被覆を保証しない。未定義の事前や不適切事前へ無条件に拡張しない。

評定者の最後の自由度を和・積の制約で再構成するraw事前には、[既知のラベル依存性](mgmfrm-first-acceptance.md#評価者の順序はモデルの一部)がある。本書の不変量も、その事前依存から免除されない。尤度の識別性、事後の存在、評定者交換可能性は三つの別の性質である。raw・source・exchangeable事前の用途別選択は、この整理に続く課題として残る。

## 7. 今回閉じた範囲と残る判断

今回の成果は、宣言した条件での同値類の導出、推定対象の分類、properな事後の存在、実装に接続した反例検査である。MGMFRM全体の数学的基盤や統計的受入が完成したという結論ではない。

利用目的に合う原点・単位・評定者事前の選択については、後続の[事前選択レビュー](mgmfrm-prior-choice.md)で、三つの候補の役割・交換可能性・尺度の対応を整理した。その後に、固定した主張に対する計算誤差・実質的許容幅と検証を対応させる。疎デザインや交差負荷への一般化は別途条件を導く。現在の269件を実行することは、これらの判断の前提でも代替でもない。
