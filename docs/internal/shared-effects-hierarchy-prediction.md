## 2. 共有効果の最初のモデルと識別条件

まず固定係数、共通カテゴリ、宣言したpure Qを対象にする。person (p)、物理課題 (t)、criterion (c)、rater (r)、response (e=(p,t,o)) を分け、候補の隣接logitを

```math
\log\frac{P(Y_n=k)}{P(Y_n=k-1)}
=\theta_{p,d(c)}-b_t-v_c-s_r-\tau_{c,k}
 +u_{p,t}+a_e+h_{r,e}-w_{r,c}
```

と書く。最初は (u_{p,t}\sim N(0,\sigma_u^2)) だけを加え、残りの追加項は無効にする。testletが実際のまとまりなら (u_{p,\ell}) を使い、物理課題との同一視はしない。`task` / `testlet_id` / `response_id` を渡しただけでは項を増やさない。新しい共有効果は平均ゼロの母集団分布を持ち、観測されたセルでの追加の和ゼロ制約は既定にしない。位置の基準と事前による固定は4ファセットの仕様から継承する。

次に (h_{r,e}\sim N(0,\sigma_h^2)) を加え、同じ評定者が同じ応答の複数観点を採点した共有変動を扱う。反復応答があるときだけ (a_e\sim N(0,\sigma_a^2)) を別候補にする。一課題一応答では (u_{p,t}) と (a_e) は同じグループなので、同時投入しない。すべての追加効果を同時に有効にする推奨ではない。

共有効果の係数は初期モデルでは+1に固定する。comprehensibilityとaccentednessではカテゴリの高低の意味を先に宣言する。向きを揃える再符号化も記録する。共通の+1が妥当でない尺度に自動適用しない。効果の係数と標準偏差を両方自由にすると積の尺度が不定になるため、自由な効果負荷量は別の拡張とする。

### 共分散から見える分離と反例

固定した負荷量のGaussian潜在予測子では、同じ人物の異なる課題・評定者間の関連が能力共分散を、同じperson–task内の異なる評定者間の追加関連が共有課題変動を、同じrater–response内の追加関連が (h) を区別する手掛かりになる。これは候補の説明の比較であり、心理的haloの因果機序の同定ではない。

[数学検査](../../scripts/shared_effect_hierarchy_audit.py)は、2観点の自由な能力共分散の3成分、person–task、rater–response、和ゼロrater、二重和ゼロrater–criterionの共分散行列を作り、上三角要素を並べた列の階数を**有理数で**検査する。必要に応じresponse–occasion成分を追加する。

| 小設計／反例 | 成分数 / 階数 | 含意 |
| --- | --- | --- |
| 2人物×2課題×2評定者×2観点、課題ごとに1応答 | 7 / 7 | この潜在共分散上では列の重なりなし |
| 同じ交差設計で課題ごとに2応答、応答効果も追加 | 8 / 8 | 安定したperson–taskと応答別成分の分離に反復応答が寄与 |
| 課題が一つ | 7 / 6 | (K_u=K_{11}+K_{22}+K_{12})。自由な能力共分散と共有課題変動を一意に分解できない |
| 課題ごとに1応答のまま応答効果を追加 | 8 / 7 | person–taskとresponseの成分が同じ |
| 評定者が一人、反復応答あり | 6 / 5 | responseとrater–responseの成分が同じ |
| 観点が一つ | 3 / 3、非対角要素だけでは2 | 共分散全体の階数が満たされても、haloセル内の複数指標がなく、その残差関連を検査できない |
| 一課題・一評定者 | 5 / 3 | 能力共分散・共有課題・rater–responseに二つの重なり |

これは将来の能力共分散を自由にした候補の反例であり、現在のpilotの識別判定を変更しない。能力分散等を固定すると制約によって区別できる場合があるが、データの反復による区別とは分けて解釈する。階数が十分でも、ordinal観測モデルの識別・尺度推定精度・弱い分散成分の回復を証明しない。既存のグラフ／Q支持監査を各訓練foldで実行し、支持の少ない疎な設計は別に評価する。

## 3. 評定者尺度の階層化と座標

### 正規化した事前とlog尺度の変換

評定者が (R) 人、(q=R-1)、(s=Cx)、(C=[I_q;-\mathbf1^\top]) とする。`rater_kernel_sd` を σと書くと、既存の正規化事前を拡張する密度は、自由座標 (dx) 上で

```math
\log p(x\mid\sigma)
=\tfrac12\log R-q\log\sigma-\tfrac q2\log(2\pi)
 -\frac{\|Cx\|^2}{2\sigma^2}.
```

周辺SDは σ√((R−1)/R)、二人の差のSDは √2σである。全R要素に正規密度を掛けるだけでは余分な −logσが入る。尺度を推定する際は落とせない。これらは**事前密度を含む対数事後**に入る項で、観測別対数尤度・WAIC/LOOの入力へ混ぜない。既存の[正規化事前の導出](../../ROADMAP.md#normalized-source-and-exchangeable-prior-reference)を再利用する。自由度に応じた尺度補正は[Stanの制約変換資料](https://mc-stan.org/docs/reference-manual/transforms.html#sum-to-zero-transforms)でも説明されている。

数値検査では例として σ~HalfNormal(A)、(y=\log\sigma) を使い、

```math
\log p(y)=\tfrac12\log(2/\pi)-\log A
 -e^{2y}/(2A^2)+y
```

とする。最後の+yは正の尺度からlog尺度へのJacobianで、和ゼロの正規化補正とは別である。A=1.3は検査用の値であり、科学的な既定事前を選んだわけではない。事前予測から単位・実用的な変動幅を確認し、事前感度を固定してから回復実験へ進む。

非中心化では (H^\top H=I_q,H^\top\mathbf1=0)、(z\sim N(0,I_q))、(s=\sigma Hz) とする。先頭R−1座標への変換のlog絶対Jacobianは (q\log\sigma-\tfrac12\log R)。この項を使う密度照合と、固定xでの

```math
\partial_y\log p(x,y)
=-q+\|Cx\|^2/\sigma^2+1-\sigma^2/A^2
```

を数値差分で検査した。実際にzを標本化する非中心化ターゲットは標準正規のzと変換済みhyperpriorを使い、さらに −qlogσを二重に加えない。R=1では和ゼロ効果の自由度が0なので、その評定者差から尺度は学習できない。

### 評定者×観点の次の単位

全体の厳しさ (s_r) と (w_{r,c}) を分ける初期候補では、各行・各列を和ゼロとする。(W=\sigma_w H_R Z H_C^\top)、(Z_{ij}\sim N(0,1)) なら自由度は(R−1)(C−1)、共分散は σ_w²(P_R⊗P_C)、セル周辺分散は σ_w²(1−1/R)(1−1/C)になる。観測数による加重和ゼロへ暗黙に置き換えない。科学的に次元別評定者平均が必要なら、その項と観点偏差を別に定義する。

まず厳しさの尺度、次にこの観点偏差を対象にする。一貫性・正の識別力・ステップの階層化は別段階で、正値／log座標上の分布と変換を改めて記録する。正規化source事前と中心化exchangeable事前も同一視しない。

### 母集団への予測と有限パネルの和ゼロは別の契約

現在の (s\sim N_{\sum s=0}(0,\sigma^2P_R)) は、訓練評定者パネルに対する分布である。R+1人として再中心化した分布の先頭R人の分散は σ²R/(R+1)になり、元の σ²(R−1)/Rから変わる。未知の評定者をappendして既存fitをそのまま使う方法は採らない。

新規評定者を扱うモデルでは、初めから母集団の (v_r\mid\sigma\sim N(0,\sigma^2)) と人口平均の位置基準を宣言する方法を優先する。有限パネルの和ゼロ座標を使って計算するなら、パネル平均と切片／位置の変換も含めた**同じ同時分布**を実装する。

一つの明示的な事前上の補完例として、(s) と独立に (m\mid\sigma\sim N(0,\sigma^2/R)) を加えれば (v=s+m\mathbf1\sim N(0,\sigma^2I)) になる。新しい評定者を旧パネル平均に対して測る (v_*-m) の分散は σ²(1+1/R)、二人の新規評定者間の共分散は σ²/Rである。この追加仮定と位置事前の整合性なしに、既存fitがこの母集団モデルの事後でもあると扱わない。検査はこの事前共分散の恒等式と、単純appendの反例までを対象にする。

## 4. 予測・分割・採点を一緒に指定する

| 予測対象 | 条件づけ／積分する効果 | 対応する評価分割 |
| --- | --- | --- |
| 既知人物・既知評定者の未観測の評定 | 既知の効果は同時事後draw。共有セルが新規なら、そのセルの効果は積分 | 評定行の留保。残った同一応答の情報を使う予測であることを記録 |
| 既知人物の新しい発話・応答 | 同じperson–taskならuを条件づけ、新しいresponse効果とrater–response効果を積分 | 応答の全観点・全評定者をまとめて留保 |
| 新しいperson–task組合せ | 既知人物能力を条件づけ、新規uとその配下の効果を積分 | person–task全体を留保。新規応答だけの留保と区別 |
| 未知の評定者による評定 | 評定者厳しさ・観点偏差・新規haloセルを、宣言した母集団分布から共同に積分 | その評定者の全データを留保 |
| 未知の受験者の回答ベクトル | 能力ベクトルを相関を保って生成し、新規u・応答効果等も積分。既知評定者等の事後不確実性も残す | person全体を留保 |
| 未知課題・項目 | その役割の母集団事前、Q、カテゴリとステップの生成契約がある場合だけ積分 | task/item単位の留保。未知の観点を単なる未知itemとして扱わない |

新規水準の状態は各効果ブロックごとに記録する。「評定者は既知」でも、その評定者×新しい応答の効果は未知である。未知効果を0に固定することは積分ではない。固定尺度の事前を使う予測は `fixed_prior`、尺度を学習した予測は `learned_population` として区別し、後者は尺度の事後不確実性も積分する。母集団平均・尺度・カテゴリ方向・共有IDをキャッシュに含める。

グループgの**共同対数スコア**は

```math
\log p(y_g\mid D_{\rm train})
=\log E_{\phi\mid D_{\rm train}}
 \left[\int \prod_{n\in g}p(y_n\mid\phi,b_g)
                 p(b_g\mid\phi)\,db_g\right].
```

同じ共有効果をグループ内で使って、積を計算してから内側の積分と外側の事後平均を行う。各行で独立に共有効果を引き直さない。実装ではdrawごとのlog likelihoodを先に合計し、log-sum-expで平均する。一方、各行の周辺対数スコアの和は Σ_n log E[p(y_n|...)] で、別の予測対象を評価する。どちらが常に優れるという関係ではない。

例として、共有成功確率が0.1または0.9（等確率）で二つとも成功なら、共同確率は0.41、周辺確率の積は0.25になる。標準正規共有効果を持つbinary logitでも、二成功の共同確率は約0.293379、周辺積は0.25である。これらは採点順序の数値検査であり、新規水準に対する実fitの予測結果ではない。

分割単位、学習／保留ID、各水準の既知／未知、尺度の由来、積分手法・精度、採点単位、集計重み、不確実性の単位を一組で保存する。新規評定者を評価するfoldでは、その人のデータがhyperparameter、前処理、潜在効果の推定へ入らないようにする。学習fold内の和ゼロ再定義で意図する母集団事前を変えない。別のモデルでも同じ対象・分割・重みで採点する。[looの階層モデルの説明](https://mc-stan.org/loo/articles/online-only/faq.html)も、既存グループ内と新規グループの予測を区別している。学習内の条件付き行別LOOを足して、新規グループ予測と呼ばない。

## 5. 診断からモデル修正を評価する流れ

1. ベースモデルと追加モデルで同じ観測ID・観点方向・診断ペア・支持条件を使う。パラメータ値の差より、共通尺度の予測と残差を比較する。
2. 既存の `_local_dependence_summary_from_probabilities`、残差計算、ペア支持監査を再利用する。現在はfitの型に結びつく入口があるため、凍結解除後にデータ／draw情報を渡せる小さな共通入口へ切り出す。ダミーの従来fitに変換して型検査を回避しない。
3. 学習済み共有効果に条件づけた複製と、新規の共有効果を生成する複製を分ける。前者だけで残差が減っても、未知の応答・評定者への予測が改善したとはしない。
4. 同一draw・同一共有ID内で依存を保った複製を使い、残差の前後差、支持不足・未定義ペア、共有効果・尺度の区間、収束とMCSE、グループ留保の予測差を返す。PPCのtail fractionやBH値を、そのまま較正済みの機序判定p値にしない。
5. 帰無・弱い効果・正の効果、能力相関のみ、haloのみ、rater–task、時間変化、疎な割当てを含む既存DGPで誤認・回復・被覆・失敗を独立反復の精度付きで評価する。単に連続正値事前の尺度が0より大きいという判定は用いず、事前に宣言した実用幅を使う。

観測行から共有セルへの整数indexを一度作り、各drawではセルごとに効果を再利用する。検査用のN×N共分散行列を推定本体へ持ち込まない。scalar共有効果の尤度追加は基本的に各行の加算で済むが、潜在次元・分散の事後形状・混合の費用は別に測る。非中心化を最初の候補とし、同一密度を確認してから情報量の多いケースの中心化と比較する。非中心化が常に速いとはしない（[Stanの階層モデルの計算説明](https://mc-stan.org/docs/2_27/stan-users-guide/reparameterization-section.html)）。

低次元の未知効果は決定的求積を照合基準にできる。高次元では同時潜在drawを使い、内側の積分誤差・外側MCMC誤差・反復間誤差を分ける。効果の事後平均を代入して積分を省略しない。速度は必要な精度でのCPU時間・実時間・ESSとメモリで比較する。経過時間の上限や追加の有料資源は導入しない。

## 7. 最初の対数密度コア（2026-10-09追記）

[four_facet_shared_target.jl](../../scripts/four_facet_shared_target.jl)を明示的にincludeする試作を追加した。packageのinclude/export、既存 `fit`、pilotは変更しない。これは `LogDensityProblems` の対数密度インターフェースを持つ新しいターゲットであり、事後fit型や既存fitを装う変換ではない。

### 今回固定した範囲と事前

入力の `FacetSpec` からはデータ・カテゴリ・Q・次元ラベルを受け取る。`item` を評価観点として明示的に使い、`task` と `response_id` が必要になる。2次元pure Q、各次元2観点以上、2人物・2課題・2評定者以上、共通カテゴリのpartial-credit、全person×task×rater×criterionセルに1評定、person×taskごとに一つの一意な応答に限る。カテゴリを同じ向きにそろえたという `category_direction=:higher_is_more` の宣言を要求する。疎なデザイン・反復応答・mixed Q・anchor/bias項等は拒否する。

実装する隣接logitは

```math
\theta_{p,d(c)}-b_t-v_c-s_r-\tau_{c,k}+\sigma_u z_{p,t},
\qquad z_{p,t}\sim N(0,1),\quad\sigma_u\sim\mathrm{HalfNormal}(A).
```

倍率は1。課題b、評定者s、次元内の観点v、観点内のステップをそれぞれ和ゼロとし、Helmertの直交座標を使う。課題・評定者・観点・ステップの各自由直交座標に、利用者が明示したkernel SDの独立正規事前を置く。これは末尾再構成の自由座標へ独立正規事前を置くこととは異なる。能力θは固定SDの独立正規、潜在相関はidentityであり、評定者尺度の学習・相関・haloはまだ加えない。

共有効果は非中心化し、自由パラメータはzとlogσ_u。hyperpriorにはlogσ_uへのJacobianを含める。これらを観測別尤度へ混ぜない。数値的にσ_uが0へunderflowする場合もlog尺度の事前項を残す。σ_uの上側overflowで対数事前が−Infになる場合は尤度評価前に返す。密度は通常の有限パラメータ空間でADを検証している。

```julia
const F = FourFacetSharedTarget

# specはcriterionをitemとして保持する2D MFRM仕様。ここで新しい役割と事前を明示する。
target = F.SharedTaskTarget(spec;
    prior=(; person_sd=.8, task_kernel_sd=.4, rater_kernel_sd=.3,
        criterion_kernel_sd=.5, step_kernel_sd=.6, shared_sd_scale=.7),
    category_direction=:higher_is_more)
x = zeros(L.dimension(target))
L.logdensity(target, x)               # 観測尤度 + 正規化した事前
F.pointwise_loglikelihood(target, x)  # 1ベクトルでの観測別尤度のみ

```
