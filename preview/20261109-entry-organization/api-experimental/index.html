Experimental Model API

Unreleased documentation preview — 13 October 2026

This manual includes unreleased interfaces and examples. It is not the documentation of an installed release. Model support and scientific acceptance remain as stated on each page.

These entries describe the callable experimental model types and functions. Their availability does not establish scientific support beyond the documented model and prior configurations. Read the experimental model guide for equations, identifying constraints, prior scales, fitting examples and limitations. For saved prediction comparison and named recovery, use the separate prediction and recovery candidate reference.

BayesianMGMFRM.Experimental — Module
BayesianMGMFRM.Experimental

Namespace for multidimensional MFRM and generalized models available in limited, experimental configurations but are not part of the stable MFRM fitting contract.

Use BayesianMGMFRM.Experimental.preview, BayesianMGMFRM.Experimental.prior_predictive_check, BayesianMGMFRM.Experimental.fit, and BayesianMGMFRM.Experimental.cached_fit instead of adding experimental = true to the stable entry points. The legacy keyword remains available for source compatibility for GMFRM/MGMFRM. Fixed-coefficient multidimensional MFRM uses Experimental.fit and manual save_fit_cache/load_fit_cache, and both prior-predictive entries; preview and automatic cache entries in this namespace still accept only GMFRM/MGMFRM.

The narrower BayesianMGMFRM.Experimental.free_latent_correlation_2d_candidate entry point exposes a density-and-gradient target only. It has no fit result or cache path through that density-only entry. Use correlated(spec) with an explicit GeneralizedPrior for the separate, limited correlated MGMFRM fitting and manual-cache workflow. The density target's companion functions expose the transformed correlation state and finite-difference gradient checks. Inspect BayesianMGMFRM.Experimental.surface_contract for the exact accepted configurations and constraints.

Result of experimental scalar GMFRM fitting. Inspect estimates with posterior_summary and sampling quality with diagnostics.

BayesianMGMFRM.Experimental.MGMFRMFit — Type

Result of experimental fixed-Q MGMFRM fitting. Inspect estimates with posterior_summary and sampling quality with diagnostics.

BayesianMGMFRM.Experimental.MultidimensionalMFRMFit — Type

Result of experimental fixed-coefficient multidimensional MFRM fitting. Use Experimental.fit(spec) to estimate and save_fit_cache/load_fit_cache to save and reopen a result.

BayesianMGMFRM.Experimental.CorrelatedMFRMSpec — Type

Two-dimensional MFRM specification with estimated population correlation. Construct with correlated.

BayesianMGMFRM.Experimental.CorrelatedMFRMFit — Type

Result of experimental correlated MFRM fitting. direct_posterior_summary and plot_posterior(...; block = :latent_correlation) report rho on its correlation scale. Reports default to reader-facing output; diagnostics must be checked before interpreting estimates.

BayesianMGMFRM.Experimental.CorrelatedMGMFRMSpec — Type

Two-dimensional between-item MGMFRM specification with estimated positive loadings, rater consistency and population correlation. Construct with correlated(spec; lkj_eta = 2) and explicitly supply GeneralizedPrior to fit.

BayesianMGMFRM.Experimental.CorrelatedMGMFRMFit — Type

Experimental correlated MGMFRM result. Supports raw/direct summaries, MCSE, diagnostics, metadata, full fit artifacts and manual save_fit_cache/load_fit_cache. Direct summaries and default MCSE report rho; raw summaries report Fisher z. Supports category probabilities and posterior prediction for existing rating rows, reader-facing reports, tables and optional CairoMakie figures. Report bundles preserve model identity, diagnostic warnings and figure inputs.

BayesianMGMFRM.Experimental.ExchangeablePrior — Type
ExchangeablePrior(; rater_kernel_sd, person_sd = 1.5, item_sd = 1.0, step_sd = 1.0)

Prior for fixed-coefficient multidimensional MFRM with exchangeable, zero-sum rater severities. Pass the same prior to prior_predictive_check and fit, with an independent specification or correlated(spec), on either backend. All scales must be finite and positive. The rater scale is required: for R raters, marginal SD is rater_kernel_sd * sqrt((R-1)/R) and pairwise contrast SD is sqrt(2) * rater_kernel_sd. It is not the independent-free-coordinate rater_sd of MFRMPrior; choosing the same number does not match those priors. Ability, item and free-step scales keep their MFRMPrior meanings. Correlated abilities additionally use the LKJ shape specified by correlated. Scales are fixed inputs, not estimated hyperparameters. Unsupported for scalar MFRM, GMFRM and MGMFRM. The default prior remains MFRMPrior().

BayesianMGMFRM.Experimental.ExchangeableMFRMFit — Type

Result of Experimental.fit(...; prior = ExchangeablePrior(...)) for independent or correlated multidimensional MFRM. Supports summaries, diagnostics, report bundles, plots, and save_fit_cache/load_fit_cache. Reports default to reader-facing output and retain the selected prior and sampler warnings.

BayesianMGMFRM.Experimental.correlated — Function
correlated(spec; lkj_eta = 2, scales = nothing)

Estimate population correlation between the named ability dimensions of a fixed-coefficient MFRM or an estimated-loading MGMFRM. For two-dimensional MFRM, pass the returned specification to Experimental.fit with backend = :advancedhmc (Julia) or :cmdstan and prior = MFRMPrior(...) or ExchangeablePrior. The input specification is copied and retains its independent-model meaning.

For three-dimensional pure-Q normalized MGMFRM (spec.family == :mgmfrm and spec.dimensions == 3), pass an explicit named tuple scales with unit person_sd = 1.0 and positive rater_sd, item_sd, log_discrimination_sd, log_consistency_sd, and step_sd to construct a BayesianMGMFRM.Experimental.Correlated3D.model Cholesky LKJ target ready for fit, prior_draw, simulate, and glass-box density evaluation.

Requires family = :mfrm, exactly two dimensions, partial-credit thresholds, between-item Q with at least two pure items per dimension, and observations in both dimensions for every person when family == :mfrm. Anchors and fitted bias terms are unavailable. Q coefficients and rater consistency are fixed at one; locations use unit logits and zero-centered priors. Direct ability pairs have covariance person_sd^2 * [1 rho; rho 1]. lkj_eta is a fixed positive integer LKJ shape on rho; it is not a standard deviation. Sampling uses rho = tanh(z) with the transformation Jacobian. A custom init ends in Fisher z, not rho.

Use prior_predictive_check before fitting, and save_fit_cache/load_fit_cache (or unified save_fit/load_fit) to save and reopen MFRM results. Automatic request caching is unavailable.

For two-dimensional family = :mgmfrm, the same 2D pure-Q and observation-coverage restrictions apply, with estimated positive active loadings and product-one rater consistency. Pass an explicit prior = GeneralizedPrior(...) to Experimental.fit; there is no implicit prior choice for this combined model. Locations/loading scales are prior-anchored and the response equation retains its literal 1.7 multiplier. Julia fitting defaults to ad_backend=:auto, selecting the exact analytic gradient for this pure-Q 2D raw-prior target. Explicit :ForwardDiff, :ReverseDiff or :analytic choices are retained. Inspect surface_contract(model).gradient_selection before fitting and the saved fit_metadata(result).sampler_controls.ad_backend afterwards. Numerical errors do not trigger an implicit backend switch. CmdStan uses its own autodiff. Both backends return CorrelatedMGMFRMFit, supporting raw/direct summaries, MCSE, diagnostics, existing-row prediction, full fit artifacts and manual save/reload. Pass the same explicit prior to prior_predictive_check before fitting. Reports, exports and optional CairoMakie figures preserve the model, prior, diagnostic warnings and conditional prediction target after reload.

BayesianMGMFRM.Experimental.joint_rating_spec — Function
joint_rating_spec(rows; criteria, prior, association = :none,
    root_criterion = nothing, parameterization = nothing,
    predictor_columns = Symbol[])

Construct an experimental multi-criterion rating-event model specification from long-format event rows, explicit criteria metadata, and an explicit prior.

  • association = :none builds a two-criterion shared-response Gaussian PCM via JointRatings.model(rows; criteria, prior, predictor_columns).
  • association = :uniform builds a two-criterion common-support paired ordinal association target via JointRatings.OrdinalAssociation.model(rows; criteria, prior).
  • association = :star builds a general D >= 2 mixed-support star-factorized ordinal association model (StarAssociation.StarModel) around root_criterion (defaulting to the criterion marked role = :root or the first declared criterion) with optional parameterization (StarAssociation.ParameterizationConfig).

All three routes support fit, design_summary, and their glass-box coordinate and density functions. Among these routes, shared prior_draw, simulate, and prior_predictive_check are available only for association=:star; they are not implemented for the shared-response (:none) or uniform-association (:uniform) targets. Check the selected model's contract for prediction, reporting, and persistence boundaries. Availability is experimental and does not imply scientific acceptance.

BayesianMGMFRM.Experimental.slope_restriction — Function
slope_restriction(spec; item_slopes, rater_consistency)

Specify a matched one-dimensional, item-step MGMFRM with item slopes :fixed_one or :estimated_positive and rater_consistency=:fixed_one. Both keywords are required. The input is copied. Its response equation is log(P(Y=k)/P(Y=k-1)) = 1.7*(a[i]*theta[p]-b[i]-r[j]-t[i,k]). The threshold owner, coefficient placement and literal 1.7 scale do not change. Fixed-one slopes map to unit-logit PCM only after rescaling locations, steps and their prior SDs by 1.7; this is not the existing scalar rater-step GMFRM.

Pass the result and an explicit NormalizedMGMFRMPrior(prior_model=:exchangeable, ...) to fit, prior_predict or prior_predictive_check. All six prior inputs remain required; log-consistency SD is inactive, and log-discrimination SD is also inactive for fixed item slopes. Fixed blocks have no sampled coordinates or density factors. These inputs do not act as near-zero-variance priors.

This first route supports Julia backend=:advancedhmc, raw coordinates and manual save_fit_cache/load_fit_cache. It returns NormalizedMGMFRMFit with the restriction bound to target identity, reduced raw coordinates and fixed coefficients reconstructed in model summaries. Inspect the order with surface_contract(model; prior).raw_parameter_names before supplying init. The default ad_backend=:auto selects the exact D1 likelihood/prior gradient, including reconstructed last severities/steps and estimated log item slopes. This also supports MeanProfilePrior. Explicit ad_backend=:ForwardDiff or :analytic requests are respected. Inspect surface_contract(model; prior) before fitting and fit_metadata(fit).sampler_controls.ad_backend afterwards. Selection does not change the model, prior measure or acceptance rules, and a numerical error does not trigger a silent switch to another gradient. Summaries, MCSE, diagnostics, existing-level prediction, reports and common K-fold refit planning retain the policy and numerical warnings. CmdStan fitting, other sampling coordinates, source priors, correlations, higher dimensions, anchors and automatic caches are unavailable through this wrapper. Supported operations do not establish recovery, SBC or model-selection performance.

BayesianMGMFRM.Experimental.GeneralizedPrior — Type

Experimental prior-scale type for GMFRM and MGMFRM fits. Its six standard deviations apply to independent normal priors on raw unconstrained coordinates, not directly to transformed model parameters. For an explicit correlated MGMFRM specification, ability pairs are conditionally bivariate normal with these marginal SDs and the specification's LKJ correlation; the other raw-coordinate priors retain their meanings.

BayesianMGMFRM.Experimental.NormalizedMGMFRMPrior — Type
NormalizedMGMFRMPrior(; prior_model, person_sd, rater_sd, item_sd,
    log_discrimination_sd, log_consistency_sd, step_sd, source_rater=nothing)

Explicit normalized prior for independent fixed-Q MGMFRM with estimated positive loadings and rater consistency. All six scales and prior_model are required. Use :exchangeable for symmetric centered blocks, or :source with an explicit source_rater ID for the reference prior with shifted log-consistency means. Rater, log-consistency and item-step scales are kernel SDs: a block of length n has marginal SD tau*sqrt((n-1)/n) and pairwise contrast SD sqrt(2)*tau. Other scales are SDs of independent normal raw coordinates. No scientific scale or default is selected by this constructor. This is distinct from the fixed-coefficient MFRM ExchangeablePrior and the raw GeneralizedPrior.

Use with fit, prior_predict and prior_predictive_check. Correlated models and automatic request caching are unavailable; use manual fit caches.

BayesianMGMFRM.Experimental.MeanProfilePrior — Type
MeanProfilePrior(model, base; item_means, step_means, category_levels, units)

Opt-in fixed location/step means for independent D1 item-owned PCM with model = slope_restriction(spec; item_slopes=:fixed_one, rater_consistency=:fixed_one) and base = NormalizedMGMFRMPrior(prior_model=:exchangeable, ...). item_means and step_means are dictionaries keyed by every actual item ID. Each step vector contains K-1 adjacent-transition means, sums to zero and excludes the structural baseline. category_levels must match the full declared order. Person and rater means remain zero; the item mean carries the reference location.

Explicit units=:raw or :unit_logit applies to the supplied means only. Unit-logit means are divided by 1.7; all six base-prior SDs remain raw-scale inputs. No numerical prior or default is chosen. Values are copied, canonicalized and bound to item/category IDs in saved results and refit requests.

Step residual covariance is step_sd^2*(I-ones(H,H)/H), H=K-1. Nonconstant means make the full step prior nonexchangeable, despite exchangeable residuals. Ordered means do not enforce hard ordering. Binary responses have zero step shape. Probabilities at prior means are not integrated prior-predictive probabilities. Use prior_predictive_check to examine the joint prior before fitting.

Supports Julia raw-coordinate fit, prior prediction, summaries, reports, existing-level K-fold refit planning and manual fit caches. Automatic caching, CmdStan fitting, free slopes, correlated/multidimensional models and learned profile hyperparameters are unavailable. This is experimental engineering support, not recovery/SBC or scientific acceptance of any application prior.

BayesianMGMFRM.Experimental.NormalizedMGMFRMFit — Type

Result of Experimental.fit(spec; prior=NormalizedMGMFRMPrior(...)). Also represents slope_restriction fits; inspect fit_metadata for the saved coefficient policy. Supports summaries, MCSE, diagnostics, existing-row prediction, manual fit caches, reports and optional figures. Its saved prior retains distribution, kernel scales and the source rater identity. Scientific acceptance is separate.

BayesianMGMFRM.Experimental.surface_contract — Function
surface_contract()
surface_contract(family)
surface_contract(correlated_spec)
surface_contract(slope_spec; prior)

Return the machine-readable stability boundary for the experimental namespace. The zero-argument form describes the executable configurations and constraints for independent fixed-coefficient MFRM and both generalized families. Pass :mfrm, :gmfrm or :mgmfrm for one family contract, or a specification returned by correlated for its correlation model contract. For slope_restriction, pass that wrapper and its explicit prior to inspect the actual free-parameter layout and Julia-only backend. Family-level backend lists do not apply to every prior/wrapper combination. In particular, fixed/free slope and mean-profile fits share NormalizedMGMFRMFit with other normalized models but have narrower fitting restrictions. Inspect fit_metadata on a saved result; the result type alone does not identify its coefficient/prior policy.

BayesianMGMFRM.Experimental.free_latent_correlation_2d_contract — Function
free_latent_correlation_2d_contract()

Return the experimental capability contract for the two-dimensional free latent-correlation density. The surface provides diagnostic operations only: it has no fit result or cache integration and does not alter the identity-correlation MGMFRM fit.

BayesianMGMFRM.Experimental.preview — Function
preview(spec)

Compile an inspectable design for a representable GMFRM or MGMFRM specification without fitting it. A successful preview does not imply that the configuration is executable; inspect surface_contract or model_equation(spec).experimental_fit_available before fitting.

BayesianMGMFRM.Experimental.prior_predict — Function
prior_predict(spec; ndraws = 1000,
    rng = Random.default_rng())

Generate score replications from the declared prior of a supported specification. Fixed-coefficient MFRM uses MFRMPrior() in unit logits; pass correlated(spec) to use its joint ability/LKJ prior. Either MFRM specification also accepts prior = ExchangeablePrior(rater_kernel_sd = ...). GMFRM/MGMFRM use GeneralizedPrior() on raw coordinates. Correlated MGMFRM requires an explicit GeneralizedPrior and uses its joint ability/LKJ prior, including the literal 1.7 response multiplier. Rows are independent replications of the existing rating design; this operation does not fit a posterior. Use a local MersenneTwister for reproducibility without advancing the global RNG.

BayesianMGMFRM.Experimental.prior_predictive_check — Function
prior_predictive_check(spec; ndraws = 1000,
    rng = Random.default_rng(), min_category_probability = 0.01,
    prior_warning_probability = 0.95, wide_facet_range_fraction = 0.8)

Generate prior parameter draws and replicated scores for a supported model. Fixed-coefficient MFRM uses MFRMPrior(); correlated(spec) also samples its LKJ correlation and conditional bivariate ability prior. The result includes the selected prior; pass prior = ExchangeablePrior(rater_kernel_sd = ...) to give all raters a common marginal severity distribution. It also includes free-coordinate draws, reconstructed model_coordinates, and a parameter_summary with central 95% prior intervals. Fixed Q coefficients, fixed marginal scales and reconstructed sum constraints retain their fitting meaning. Generalized models instead separate raw and constrained direct draws under GeneralizedPrior(). Correlated MGMFRM requires the explicit prior used for fitting; its last raw column is Fisher z and its last direct column is rho. It draws the normalized LKJ prior on rho and conditional bivariate abilities; the other free raw coordinates retain their declared normal priors.

All results work with predictive_check_summary(check) and BayesianMGMFRM.plot_predictive(check); fixed-coefficient MFRM also supports BayesianMGMFRM.plot_prior(check). Plotting requires CairoMakie. Observed ratings serve only as a comparison; they do not update the prior. Simulations reuse the supplied persons, items, raters and rating rows, not new facet levels.

free_latent_correlation_2d_candidate(spec; lkj_eta = 2)

Construct a log-density target for an exactly two-dimensional, fixed simple-structure Q MGMFRM. lkj_eta must be a positive integer. This function does not fit the model or integrate with the fit cache.

BayesianMGMFRM.Experimental.free_latent_correlation_2d_diagnostics — Function
free_latent_correlation_2d_diagnostics(spec, raw_params; kwargs...)

BayesianMGMFRM.Experimental.fit — Function
fit(spec; kwargs...)

Fit a supported multidimensional MFRM or generalized specification experimentally. Callers should not pass an experimental keyword. Family-specific structural constraints are validated before numerical execution. Pass correlated(spec) to estimate population correlation for two between-item MFRM dimensions; both backends then return CorrelatedMFRMFit when using MFRMPrior. The unwrapped configurations described below accept backend = :advancedhmc or :cmdstan, subject to their category restrictions. The slope_restriction and MeanProfilePrior routes are Julia/AdvancedHMC-only; see their separate requirements below. A supported family does not admit every prior/backend pair. For an MGMFRM correlated(spec), an explicit prior = GeneralizedPrior(...) is required. Both backends return CorrelatedMGMFRMFit; summaries, MCSE, diagnostics, existing-row prediction and manual fit caches are available. Reports and optional CairoMakie figures preserve the saved prior and diagnostic warnings; automatic request caching remains unavailable.

For independent fixed-Q MGMFRM, explicitly pass NormalizedMGMFRMPrior(...) to use normalized exchangeable/source priors and return NormalizedMGMFRMFit. Both backends support manual caches and saved-result reports/figures. This prior requires all six scales and, for :source, a distinguished rater ID. AdvancedHMC also accepts sampling_coordinates = :orthogonal_person_mean_item_offset; CmdStan requires :raw. Inspect coordinates with fit_metadata(result).sampler_controls. Automatic request caching is unavailable. This unwrapped normalized route admits binary categories on Julia; CmdStan requires at least three categories.

For slope_restriction(spec; item_slopes, rater_consistency=:fixed_one), supply an explicit exchangeable NormalizedMGMFRMPrior. The wrapper requires D1, item-owned partial-credit steps, backend=:advancedhmc and sampling_coordinates=:raw. Its optional MeanProfilePrior additionally requires item_slopes=:fixed_one and explicit item/category IDs and mean units. Both wrappers default to ad_backend=:auto, selecting the validated analytic D1 score. Explicit :ForwardDiff and :analytic requests remain available. Inspect surface_contract(model; prior, ad_backend=:auto).gradient_selection for the selected method and reason. Other model routes retain their existing defaults. Selection changes gradient evaluation, not sampling settings, the prior or the retained parameter chart; numerical errors are not hidden by fallback. Both return NormalizedMGMFRMFit and support manual caches and existing-level refit planning. CmdStan, alternative coordinates, source priors and correlated specifications are unavailable for these wrappers. Use surface_contract(model; prior) before supplying initial coordinates and fit_metadata(result) to distinguish the saved policies.

The independent MGMFRM kernel also accepts dimensions=1 with an explicit all-active, one-column Q. This is an item-step generalized model for comparison with higher-dimensional MGMFRM, not the existing rater-step scalar GMFRM. It retains the 1.7 likelihood constant, coefficient placement and prior rules. Matching the model structure does not establish predictive superiority or calibration. The correlated wrapper still requires two dimensions.

An unwrapped independent MGMFRM with GeneralizedPrior accepts sampling_coordinates = :orthogonal_person_mean_item_offset with AdvancedHMC. This rotates person coordinates and shifts item coordinates while preserving the complete joint prior and likelihood. Initial values and jitter use raw coordinates; returned draws and diagnostics also retain their raw/model meanings. The default is :raw. Automatic request caching distinguishes the optional coordinates; default cache keys are unchanged. The option does not apply to correlated specifications or fixed-coefficient multidimensional MFRM.

An unwrapped fixed-coefficient multidimensional MFRM (family = :mfrm, dimensions >= 2, fixed q_matrix, partial-credit thresholds) has independent abilities. Use MFRMPrior for independent normal priors on free unit-logit coordinates. Q coefficients and rater consistency are fixed; latent correlation is identity and locations are prior-anchored. With MFRMPrior, both backends return MultidimensionalMFRMFit, with warmup sampler statistics recorded by default (record_warmup = true). Save and reload with save_fit_cache/load_fit_cache; automatic request caching is unavailable. The shared independent generalized AdvancedHMC routes also accept chain_execution=:threads and max_parallel_chains; default serial streams are unchanged. Correlated wrappers and fixed-coefficient multidimensional MFRM do not support these options. See the fitting guide for RNG, progress and memory behavior. Shared sampler controls include ndraws, warmup, chains, seed, init, step_size, target_accept, max_depth, and stored diagnostic thresholds. CmdStan additionally accepts cmdstan_path and cmdstan_cache_dir. For exchangeable zero-sum rater severities, explicitly pass prior = ExchangeablePrior(rater_kernel_sd = ...). Both independent and correlated specifications then return ExchangeableMFRMFit, with the same summary, report, plotting and manual cache operations.

BayesianMGMFRM.Experimental.JointRatings — Module
BayesianMGMFRM.Experimental.JointRatings

Experimental two-criterion shared-response PCM workflow. A response is one person's production on one physical task; a rating event is one rater's assessment of that response. Their IDs are not interchangeable.

Use model, fit, save_result/load_result, report, contrast, predict, and score through this namespace. predict returns marginal category probabilities; score integrates ratings of the same response jointly. Read contract() before use. This local API candidate has no scientific acceptance, stable API guarantee, or general-purpose MGMFRM model-selection claim.

BayesianMGMFRM.Experimental.JointRatings.contract — Function
contract()

Return this candidate's supported model, prediction and persistence boundaries. Available operations are not evidence of convergence or scientific acceptance.

BayesianMGMFRM.Experimental.JointRatings.model — Function
model(rows; criteria, prior, predictor_columns=())

Validate a two-criterion PCM with shared response effects, fixed unit coefficients, correlated person abilities and correlated response effects. Rows are named tuples with observation_id, person, task, response_id, rating_event_id, rater, criterion (nonempty strings), and integer score. Each criterion declares criterion, increasing integer levels, direction (:higher_is_more/:higher_is_less), and threshold_group. Declare the full possible support, including unused categories. Both criteria need the same category count. Missing/recused ratings are omitted, never converted to zero.

prior explicitly supplies task_sd, two rater_sd, one step_sd per sorted threshold group, two response_log_sd_mean, two response_log_sd_sd, one beta_sd per named predictor, person_lkj_eta, and response_lkj_eta. Criterion vectors follow sorted criterion IDs. Rater/step SDs are Helmert kernel SDs; response log-SDs have normal priors. Person marginal SDs equal one. Numeric predictors retain their supplied units; no intercept is added. At least two persons/tasks/raters and both criteria per person are required. Validation does not establish covariance identification or adequate precision. No fitting or random generation occurs here. See the Joint Ratings guide.

BayesianMGMFRM.Experimental.JointRatings.fit — Function
fit(model; backend=:advancedhmc, compiled=nothing, ndraws, warmup, chains,
    seed, target_accept=.9, max_depth=10, step_size=.03, init_jitter=.1)

Explicitly start sampling and retain raw draws, warmup, controls and warnings. There is no automatic extension or accepted prior default. The :cmdstan backend requires compiled=verified_stan(directory) from a matching successful native finite check; it neither installs nor compiles Stan automatically. Use report to inspect the result and save_result to preserve it. Julia uses ad_backend=:auto to select the exact analytic gradient; explicit :ForwardDiff and :ReverseDiff remain available. run.controls.ad_backend records the selected backend. Julia also accepts progress=SamplingProgress(...). Available backends do not establish posterior accuracy or recovery performance.

BayesianMGMFRM.Experimental.JointRatings.verified_stan — Function
verified_stan(directory)

Verify a successful native-check receipt against the bundled Stan source and the executable hash. Return the compiled descriptor required by fit. No compilation, package installation or sampling occurs.

BayesianMGMFRM.Experimental.JointRatings.load_result — Function
load_result(path)

Read a trusted native sample file and validate its model, content identity, draws and retained densities. Native Julia serialization is not a portable cross-version format and must not be used for untrusted files. Nothing is fit.

BayesianMGMFRM.Experimental.JointRatings.save_result — Function
save_result(path, result)

Validate and save a native sample record without overwriting an existing file. Retains model, prior, raw draws, controls, diagnostics and content identities. Use the original Julia and dependency environment for native replay.

BayesianMGMFRM.Experimental.JointRatings.report — Function
report(result; lower=.05, upper=.95, intervals=(.9,))

Return model/prior metadata plus parameter summaries, raw/model diagnostics, MCSE, sampler and warmup warnings in .result. For 99% equal-tailed intervals, use lower=.005, upper=.995, intervals=(.99,). These are not HDIs. The report is descriptive and never upgrades an unqualified saved fit.

BayesianMGMFRM.Experimental.JointRatings.contrast — Function
contrast(result; facet, criterion, left, right, interval=.90, rope=nothing)

Summarize a same-criterion person or rater difference, left - right, from a trusted saved JointRatings result. Use facet=:person or :rater and exact stored string IDs. All original draws retain their chain order and pairing. The .result.summary contains an equal-tailed interval, mean/endpoint MCSE, event probabilities and contrast diagnostics. An optional (lower, upper) ROPE uses the same unit-logit scale; its bounds are inclusive.

A positive person difference means more of the criterion's canonical trait; a positive rater difference means greater severity (lower canonical scores). The declared raw-score direction is retained in .result.criterion. These are latent effects, not raw-score differences or response-level predictions. category_predictive_check(result; rater, group, category,

Check one observed rater/group category count using every retained joint draw. Returns the expected count and inclusive probabilities P(Nrep<=Nobs), P(Nrep>=Nobs), and P(Nrep==Nobs), with chain-aware mean MCSE, focal diagnostics and whole-fit warnings. The two inclusive tails sum to 1 plus the point mass; they are not complements, a two-sided p-value or calibrated rejection rules.

Conditional on each draw, the selected rating indicators are independent with their row-specific category probabilities. Their Poisson-binomial distribution is integrated exactly by a positive coefficient recurrence, then averaged over draws. This retains posterior dependence and heterogeneity; substituting average probabilities or a single binomial distribution changes the calculation. Prediction repeats the same people/items/rater/group allocation. No new levels, shared response/class effects, conditional-probability intervals or count quantile intervals are provided. No fitting, predictive RNG or subsampling occurs.

The recurrence uses O(Sn^2) work and 4S+n+1+K Float64 workspace cells, excluding coordinate reconstruction, sample validation and diagnostics. The explicit count-update budget is Sn(n+3)/2; exceeding it raises an error. Small sampled probabilities may underflow; a constant sampled function has unavailable MCSE, not proof of zero probability. Support-fixed inclusive tails are labelled fixed.
