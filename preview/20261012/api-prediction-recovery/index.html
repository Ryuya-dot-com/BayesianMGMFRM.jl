Prediction and Recovery Candidate API

Unreleased documentation preview — 12 October 2026

This manual includes unreleased interfaces and examples. It is not the documentation of an installed release. Model support and scientific acceptance remain as stated on each page.

These qualified functions are available in this isolated candidate, which has not been merged or released. Use BayesianMGMFRM. when calling them. They consume existing data specifications, fit caches or evaluation records; they do not automatically fit candidate models or choose a winning model or design.

The saved prediction and recovery guide connects these operations to saved-fit examples, model/dimension/Q choices, diagnostic warnings, failure accounting and interpretation limits. Existing exported comparison and vector-truth recovery APIs retain their meanings.

Existing-row prediction and comparison

These methods evaluate fitted levels. WAIC and raw importance-sampling LOO are training-data approximations; they are not heldout K-fold scores, reference-validated PSIS or new-level prediction. See each function's supported inputs and uncertainty limits.

BayesianMGMFRM.PredictionObservationAdapter.prediction_observations — Function
prediction_observations(fit; dataset_id, observation_ids,
    ndraws=nothing, draw_indices=nothing, rng=Random.default_rng(),
    include_probabilities=true)

Extract conditional predictions for ALL original fitted rows of the eight supported fit types. Supply persistent observation IDs in that fit's row order; row numbers and response-group IDs are not automatically promoted to outcome IDs. dataset_id names the shared source dataset. IDs and native labels/scores are bound together, including optional metadata, in a row-order-independent hash.

Returns draws × observations pointwise log likelihood, optional draws × observations × categories probabilities, selected chain/iteration IDs, model scale/constraints/prior metadata and diagnostics. Selection preserves duplicates. Probabilities and likelihood share one stable logit evaluation. Setting include_probabilities=false avoids allocating the category array. No prior or Jacobian enters the likelihood. Diagnostic warnings are retained, not filtered.

This does not accept new rows, folds, weights, new facet levels, or a replacement prediction target. The result is training-row, existing-level conditional prediction. It is not a fitted-CV result or a scientific acceptance decision.

BayesianMGMFRM.PredictionObservationAdapter.observation_alignment — Function
observation_alignment(reference, candidate)

Return candidate column indices in reference outcome order after checking source dataset, outcomes, categories and conditional training target. Different latent models may align; this is not permission to compare their parameter values, an automatic comparison-axis choice, or a WAIC/LOO ranking function. Arrays are not copied. Draws from different fits need not have the same counts or RNG streams.

BayesianMGMFRM.PredictionObservationAdapter.prediction_criteria — Function
prediction_criteria(prediction; criteria=(:waic, :raw_loo), ...)
prediction_criteria(fit; dataset_id, observation_ids, criteria=..., ...)

Compute native criteria once from the common full retained log-likelihood matrix. Allowed names are :waic, :rawloo (native loo), and :hillsmoothedloo (native psisloo). The latter is the repository's Hill-tail smoother, not an assertion of equivalence to the reference loo package. No refit or ranking is performed.

All original chains and draws are required. Retain sampling and criterion warnings, including affected observation IDs. Native pointwise SE is not MCMC MCSE or a cluster/replication SE; native importance ESS is not autocorrelation adjusted. The LOO target omits one rating with specification/level maps fixed, not a person, response group, or new-level prediction task.

BayesianMGMFRM.compare_predictions — Function
BayesianMGMFRM.compare_predictions(models::Pair...;
    comparison_axis, criterion=:waic, baseline=nothing, se_unit=:none,
    dataset_id=nothing, observation_ids=nothing, ...)

Compare two or more supported fits, or two or more prediction_observations bundles, on the same original rating outcomes. For fits, supply dataset_id and unique observation IDs: a vector shared by all fits, or a dictionary from model labels to vectors in each fit's row order. For bundles omit both keywords. All original draws/chains are used; different fit draw counts are permitted.

Declare comparison_axis=:model (same D/Q), :dimensions (D and Q may differ), or :q_matrix (same D). Family, priors, scales and correlation metadata are retained; an axis label alone does not isolate a causal effect of that choice. Allowed criteria are :waic, :raw_loo, and :hill_smoothed_loo; the last is the package's non-reference-validated Hill smoother, not validated PSIS.

Rows retain input order. ELPD differences are model minus the declared baseline (first model by default), not an automatically selected winner. se_unit=:none leaves difference SE missing; :observation assumes exchangeable rating units; :person sums differences within person before computing the approximate SE. The latter is one-way clustering under an exchangeable-person assumption, not a correction for arbitrary crossed rater/item dependence. These SEs are neither MCMC MCSE nor repeated-data simulation uncertainty. One unit gives missing SE.

Warnings, problem observation IDs and model identities remain in each row. This is an existing-level rating-omission approximation, not refitted K-fold, new-person/rater prediction, scientific acceptance or automatic model selection.

Known-level K-fold preparation and scoring

Prepare the same declared split for each candidate model, then supply the matching saved training fits. The complete planned fold roster determines missing/failed status. Aggregation does not estimate K-fold uncertainty or execute refits.

BayesianMGMFRM.prediction_refit_plan — Function
prediction_refit_plan(model, plan; prior, dataset_id, observation_ids)

Prepare all K-fold training requests without sampling. model is a FacetSpec or a supported Experimental.correlated(spec) model; prior is explicit. The existing K-fold partition and known-level checks run before any request is returned. Model, Q, dimension names, prior and supported covariance are retained. Persistent unique rating IDs are supplied in the source specification's row order.

Each folds entry exposes model and prior for fit (scalar MFRM) or Experimental.fit (other supported models), and is bound to the full source, split, training target and heldout order. Use prediction_fold_observations to score its independently fitted training result. No full-data fit, posterior initialization, backend choice or sampler control is inferred. Specify priors before examining heldout outcomes; this API cannot detect prior/model tuning.

Only existing person/rater/item/category levels are supported. Optional grouping metadata do not become fitted effects. This is not an automatic refit executor, LOO repair, or a new-level marginal prediction API. Use prediction_kfold and compare_kfold_predictions to aggregate and compare the saved heldout results.

BayesianMGMFRM.prediction_fold_observations — Function
prediction_fold_observations(training_fit, request; include_probabilities=true)

Score one prepared K-fold request using all original retained training-fit draws and chains. Reject changed requests and fits for different training observations, model, prior or covariance. Saved records undergo their native integrity checks. Heldout native labels are mapped to the actual training parameter order; the existing likelihood kernel is shared with prediction_observations.

Returns heldout draws × rows log likelihood, optional category probabilities, persistent IDs, source/split/target bindings and unfiltered sampling diagnostics. Correlated draws already contain the joint ability transform; it is not applied again. Heldout results have a distinct schema and cannot be passed to training-row WAIC/LOO. No convergence qualification, fit execution receipt, or predictive comparison is inferred from a matching target. Legacy fixed-MFRM v1 records are not migrated into canonical refit targets.

BayesianMGMFRM.prediction_kfold — Function
BayesianMGMFRM.prediction_kfold(prepared, scores; failures=Pair[])

Aggregate prediction_fold_observations results against the original complete prediction_refit_plan. Results may arrive in any fold order. Explicit failures are fold ID => nonempty reason pairs; absent results remain :missing. Duplicate, foreign or edited records are rejected. All retained draws/chains are used.

Each rating's score is log(mean(exp(loglikelihood))) over its training posterior. Scores are additive over ratings, even for grouped splits; this is not a joint group predictive density. Any missing/failed fold leaves the full ELPD missing. Diagnostic warnings retain all scores and mark the result as a warning. No folds are discarded. SE, MCMC MCSE and repeated-data uncertainty are not computed. This descriptive result neither qualifies convergence nor selects a model.

BayesianMGMFRM.compare_kfold_predictions — Function
BayesianMGMFRM.compare_kfold_predictions(models::Pair...; comparison_axis, baseline=nothing)

Compare named prediction_kfold results on the identical source and K-fold split. Declare :model (same D/Q), :dimensions (D/Q may differ), or :q_matrix (same D). Input order is retained; differences are model minus baseline (first by default). IDs align the individual rating scores. If any model is incomplete, all contrasts remain missing. Diagnostic warnings remain visible and never remove a fold/model. No automatic ranking, winner, weights or uncertainty estimates are produced. Fold dependence is not approximated by treating folds as independent replications.

Named truth and independent-dataset summaries

Truths must use the model's native scale and identifying constraints. Structural constants do not count as estimated coverage. Summaries of fixed-truth replications require the full dataset roster and a documented independence declaration before reporting replication SE; this neither verifies generation nor performs SBC.

BayesianMGMFRM.recovery_quantities — Function
BayesianMGMFRM.recovery_quantities(fit)

List supported named model-coordinate quantities of a saved fit, including dimension labels, units, structural constants and native derived quantities. All eight supported fit types use their existing report/plot reconstruction; canonical fixed-MFRM records are required. No plotting dependency is needed. Use these exact names as keys for recovery_evaluation. This is an inventory, not raw sampler coordinates or a mapping between different latent models.

BayesianMGMFRM.recovery_evaluation — Function
BayesianMGMFRM.recovery_evaluation(fit, truth::AbstractDict;
    dataset_id, observation_ids, interval=0.95)

Evaluate named simulation truths for one dataset, using all retained draws and chains. Keys are exact names from recovery_quantities; nonempty subsets are allowed. Truths must already use the fitted model's scale, labels and identifying constraints. No truth centering, latent alignment or across-model mapping is inferred. This function cannot establish that the supplied values generated data.

Reuses native bias/interval recovery arithmetic and MCMC MCSE. Sampling warnings are retained. Estimated quantities have central-interval coverage; structural constants have covered=missing, coverage_applicable=false and a separate fixed-value/truth agreement flag. Their point intervals are not calibration evidence. Interval-endpoint MCSE is neither a coverage-decision error bound nor simulation replication uncertainty, and no precision threshold is applied.

Returns a source-bound, content-hashed record with per-quantity rows and explicit single-dataset scope. This neither fits/generates data nor pools replications, performs joint-prior SBC, compares models, or establishes design adequacy. Existing vector-truth parameter_recovery methods are unchanged.

BayesianMGMFRM.recovery_replications — Function
BayesianMGMFRM.recovery_replications(evaluations;
    planned_dataset_ids, parameters, scenario_id, dataset_independence, failures=Pair[])

Summarize sealed recovery_evaluation records for one declared fixed-truth design scenario. Declare the full dataset roster and exact focal quantity names before examining results. Each quantity receives one observation per dataset; quantities, persons, chains and folds are never pooled as independent replications. Changed model/prior/scale/interval contracts and varying focal truths are rejected.

failures maps planned dataset IDs to nonempty reasons. Missing results, failures, missing quantities, fixed constants and warnings remain in the output ledger. all_completed includes numerical warnings; without_warnings excludes sampling warnings, unavailable focal MCSE and any fixed-truth mismatch. The latter is a descriptive subset, not a precision-qualified or scientifically accepted result. Structural constants receive neither recovery summaries nor coverage credit.

Supply dataset_independence=(status=:declared_independent, evidence="..."), or :unresolved with an explanation. The declaration concerns independent datasets from the same scenario, not independent chains. Replication SE is sample SD / sqrt(n) only for declared independence with at least two retained datasets. Reused evaluated evidence suppresses SE despite a declaration. RMSE uses the first-order delta method; zero MSE leaves its SE unavailable. Zero empirical variance is explicitly flagged.

Coverage bounds assign unresolved outcomes both 0 and 1 in the planned denominator; they are not confidence intervals. No MCMC error correction, coverage-decision error bound, seed/generator/design verification, SBC or design adequacy decision is made.
