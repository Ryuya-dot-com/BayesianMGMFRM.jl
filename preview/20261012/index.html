BayesianMGMFRM.jl

Unreleased documentation preview — 12 October 2026

This manual includes unreleased interfaces and examples. It is not the documentation of an installed release. Model support and scientific acceptance remain as stated on each page.

See the Visualization Gallery for Wright Maps, Pathway Maps and MGMFRM response surfaces with worked reading guidance.

BayesianMGMFRM.jl provides conservative Bayesian workflows for many-facet Rasch measurement. It combines long-format rating-data validation, identified model construction, Bayesian fitting, diagnostics, predictive checks, portable reports, and optional figures directly from saved or newly fitted models.

New to Many-Facet Models?

Start with the beginner's guide. It follows a concrete rating example and separates the research question, data design and model choice. No Julia or Bayesian modeling experience is needed to read it.

  1. Getting Started: persons, items, raters, dimensions and the differences between MFRM, GMFRM and MGMFRM.
  2. How Rating Models Work: category probabilities, a worked calculation, priors, identification and ability correlation.
  3. Reading Results and Comparing Models: uncertainty, diagnostics, predictive comparison and simulation for study planning.

For executable Julia workflows, continue to the short runnable examples.

What Is Supported

The stable fitting surface covers MFRM with rating-scale or partial-credit steps. The following additional configurations require explicit experimental opt-in:

  • a fixed-coefficient multidimensional MFRM with independent abilities;
  • a two-dimensional between-item MFRM with estimated population correlation;
  • a one-dimensional scalar GMFRM with item discrimination and rater consistency;
  • a multidimensional fixed-Q confirmatory MGMFRM with independent abilities;
  • an explicit two-dimensional correlated MGMFRM, currently covering fitting, summaries, diagnostics, MCSE, prior/conditional posterior prediction, manual caches and report/figure bundles. This workflow remains experimental.

Broader discrimination structures, exploratory loadings, higher-dimensional correlation estimation, and fitted DFF effects are not supported. See Scope and Releases for the exact boundary and Experimental Models for the limited API. Before choosing MGMFRM, review what is estimated and what is fixed: its fixed Q pattern still has estimated active loadings, and its rater consistency parameter has a different meaning from reliability.

Recommended Path

The sequence below uses the stable MFRM entry points. For multidimensional MFRM or GMFRM/MGMFRM, follow the model-specific fitting and prior routes.

  1. Build long-format ratings with FacetData.
  2. Run validate_design and inspect coverage, connectedness, category use, optional groups, and anchors.
  3. Create an mfrm_spec and review its constraints. getdesign provides optional parameter inspection.
  4. Use prior_predictive_check before fitting.
  5. Call fit(spec) for the supported stable model.
  6. Review sampler_diagnostics, mcmc_diagnostics, parameter_block_diagnostics, and diagnostics.
  7. Inspect estimand-specific posterior_mcse, posterior, predictive, calibration, residual, and sensitivity results. The plotting guide shows figures from a fit.
  8. Export fit_report(fit; view = :public) or fit_report_public for reader-facing structured data, or use fit_report_markdown for Markdown. Check report completeness with fit_report_health or set require_complete = true.
